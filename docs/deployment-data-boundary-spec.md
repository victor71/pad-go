## 1. 目的与范围

本规范把产品决策（本地存储权威源、儿童数据不持久上云、导出导入、家长同意、云端推理、家长端直连）转化为可评审的边界条款。核心思路：**存储与处理分离**——数据的唯一权威副本留在本地，出设备的每个通道（推理调用、家长直连）都约束为受控白名单（第 7 / 8 章）。

部署形态同时界定了规模量级：单设备、儿童数为家庭规模（1–3 个档案）、知识点千级、日证据十条级——存储与索引选型按此量级设计，遵循记忆规范第 11 节 YAGNI。

## 2. 部署拓扑

### 2.1 本地唯一权威源（必须）

儿童档案的一切记忆数据——证据日志、记忆条目、学情状态、审计日志、同意记录——的**唯一权威副本在设备本地**。**不得**存在云端副本、云备份、云同步通道。

### 2.2 出设备白名单（必须）

出设备的通道实行**白名单制**，仅限四类：下行内容包（2.3，只读）、推理调用（第 7 章，最小必要上下文）、匿名诊断数据（3.3，C5 同意 + 不可逆识别）、家长端直连（第 8 章，配对验证 + 加密）。白名单之外的任何外发均禁止（BD-07）。

### 2.3 下行内容管道（必须）

内容与元数据（题目、kp 注册表、前置图、关联、难度表、话术模式库更新）以**只读内容包**形式分发到设备——知识契约第 6 章的元数据快照即内容包形态。内容包**必须**验签后生效（内容投毒防线，呼应记忆规范 8.3）。下行管道不承载任何儿童数据。

### 2.4 时间源约束（必须）

关键时钟——每日预算（生命周期规范 9）、掌握度衰减、重验间隔、TTL——**必须**基于单调时钟语义与持久化的可信时间锚；设备时钟回拨**不得**重置每日预算、**不得**倒转衰减、**不得**位移重验调度。具体机制（单调钟 + 周期性安全校时）属方案层。

### 2.5 离线分级独立性（必须）

记忆系统操作分两级，离线语义不同：

| 级别 | 操作 | 离线行为 |
| --- | --- | --- |
| 数据级（无推理依赖） | 答题类证据采集、状态机演化、复习调度、本地检索、导出 / 导入、家长直连 | 正常可用 |
| 智能级（依赖云端推理） | 对话生成、语义记忆提取、对话类证据评估、主动沟通、前兆信号中的对话内容分析（《压力与难度调节规范》8.1） | 暂停，输入持久排队 |

- 排队输入联网后**必须**补处理，且**必须**携带**事件发生时间**而非处理时间——否则长离线后的衰减与预算计算失真；
- 离线期间前兆检测仅剩行为类信号（响应时间 / 跳过 / 模式化作答 / 中途退出），检测能力**降级**；该降级**不得**导致加压条件放宽（保守优先，见《压力与难度调节规范》8.1）；
- 离线降级的产品呈现（提示语、功能遮蔽方式）属方案层。

### 2.6 宿主形态（必须）

产品决策：儿童使用独立设备、家长使用手机，且**儿童端代码框架可适配两种宿主**（独立学习设备 / 手机）。本规范全部条款（本地权威源、白名单、导出导入、同意框架、推理约束）对**每种宿主同等生效**，并补充：

1. **档案权威随宿主**：同一儿童档案在多个宿主上的使用各自独立积累，**不得**实时同步；跨宿主合并仅经导出 / 导入（第 5 / 6 章，幂等并集 + 重放）；
2. **推理通道不因宿主分叉**：无论宿主算力如何，LLM 推理一律经云端推理服务与推理网关（第 7 章）——**不得**因手机算力较强而引入本地 LLM 分支，保持单一外发通道与统一审计；本地嵌入（7.1）在所有宿主执行，模型规格（量化档位）可按宿主配置；
3. **宿主为手机时，家长侧可为同机家长模式**：验证、加密、受众隔离、删除级联语义与直连通道一致（第 8 章），**不得**因同机而豁免任何一项。

## 3. 数据分级

| 级别 | 内容 | 存储 | 出设备 |
| --- | --- | --- | --- |
| 儿童个人数据 | 证据、学情、画像、兴趣、审计、同意记录 | 仅设备本地 | 禁止（导出文件除外，第 5 章） |
| 内容元数据 | 题库、kp、前置图、关联、难度 | 本地缓存，随内容包更新 | 下行单向 |
| 匿名诊断数据 | 崩溃日志、聚合指标 | 本地暂存 | 仅家长同意且不可逆识别 |

### 3.3 匿名诊断数据（可以 + C5 同意）

默认关闭；开启后传输数据**不得**包含儿童标识、档案内容或任何可逆识别信息；**必须**能被出网流量审计（BD-07 / BD-08）验证。

## 4. 家长同意框架

### 4.1 同意项（必须）

| ID | 事项 | 缺省与节奏 |
| --- | --- | --- |
| C1 | 启用记忆系统 | 默认关；未同意则记忆功能不可用 |
| C2 | 数据导出 | 每次导出单独验证（授权不常驻） |
| C3 | 数据导入 | 每次导入单独验证 |
| C4 | 档案删除 | 每次单独验证 |
| C5 | 匿名诊断数据 | 默认关 |

C1 未同意期间：记忆功能不可用，但主动沟通**不得**因此退化为纯被动应答（伴学规范 5.2 立场 2）——可使用非记忆锚点（课程结构、当日内容、通用引导）；该状态**应当**只存在于首次引导流程中（与 C1 引导绑定，尽快消解）。

### 4.2 验证与审计（必须）

同意、验证、撤回事件均**必须**留审计（谁、何时、何同意项——与记忆规范 8.4 同构）。家长身份验证机制属方案层，强度**应当**与操作风险匹配（导出 / 删除 > 启用）。

### 4.3 撤回语义（必须）

撤回 C1 = 记忆系统**停用**（停止写入与检索），数据保留；数据删除仅走 C4。两者不混同——撤回是可逆的功能开关，删除是不可逆的数据处置。

## 5. 导出契约

### 5.1 粒度与范围（必须）

按**儿童档案**粒度导出；内容**必须**完整覆盖该档案全部记忆数据与重放所需的一切：证据日志、记忆条目、时钟参数、指向的元数据版本。

### 5.2 保护（必须）

导出文件**必须**认证加密（机密性 + 完整性），明文字段为零；导出操作需 C2 验证。导出文件是儿童数据离开设备的**唯一**形态，其泄露等同于 AP-LC-11 事故，保护等级按此设计。

### 5.3 重放一致性（必须）

导出 → 空设备导入 → 全量重放，结果与导出前状态**完全一致**——这是 X-01 重放不变量在导出场景的延伸（BD-03）。可重放架构使导出天然最小化：状态是派生的，日志才是本体。

## 6. 导入契约

### 6.1 验签（必须）

导入前**必须**验证文件完整性与来源；验证失败**整体拒绝**，**不得**部分导入（导入是投毒攻击面，BD-05）。

### 6.2 合并语义（必须）

导入 = 证据日志按 `evidence_id` **幂等并集** + 记忆条目按既有裁决规则合并（记忆规范 7.1 / 7.2）+ 全量重放。导入后 X-01 一致性**必须**成立（N-02 / BD-04）。

### 6.3 信任不升级（必须）

导入恢复的证据保留其**原来源可信级**，不因"通过验证的导出文件"获得额外信任。

## 7. 推理位置与最小必要上下文（必须）

产品决策：推理在云端 LLM 进行，本地设备不具备生成式推理能力。本规范不禁止记忆上下文出设备，而是将其约束为**受控的处理通道**：

### 7.1 本地职责（必须）

存储、检索、筛选、脱敏与 prompt 组装全部在设备本地完成——记忆系统即是**隐私网关**：出设备的只有组装完成的推理请求，而非档案本身。记忆文本的向量化（嵌入计算）**应当**在本地完成（小型嵌入模型），否则写入路径每次都外发原文。

### 7.2 最小必要上下文（必须）

发送到推理服务的内容**必须**限于：当前对话历史 + 检索截断后的记忆条目（≤ prompt 截断上限，记忆规范 6.2）+ 系统指令。**不得**发送：全量档案、家长标注等隔离级记忆（AP-LC-10）、加密受限记忆（记忆规范 8.2）、审计日志、其他儿童档案的数据。

**"可进入儿童对话 prompt 的内容 = 可发云端推理的内容"**——一个口子，检索准入与外发准入共用同一套规则。

### 7.3 推理服务约束（必须）

推理服务**必须**满足：零数据留存（处理即弃）、不得用于模型训练、传输全程加密；具体由数据处理协议保障（法务层）。

### 7.4 调用审计（必须）

每次推理调用**必须**留本地审计（时间、目的、包含的记忆条目数与来源 kp）——BD-10 的依据。**红线**：向推理服务发送 7.2 禁止清单中的内容，为方案评审一票否决项。

## 8. 家长端形态（必须）

家长端为手机 App，与儿童端宿主的通道为**蓝牙 / WLAN 直连**（点对点，不经互联网服务器；儿童端宿主为手机时可为**同机家长模式**，验证与加密语义不变）：

- **配对验证（必须）**：直连通道建立前必须完成设备与 App 的配对验证；未配对的近场接入一律拒绝（防近场攻击面，BD-09）；配对与家长身份验证机制属方案层；
- **传输加密（必须）**：直连通道全程加密；
- **不经云中转（必须）**：家长 App 与设备间**禁止**经互联网云端同步或中转（AP-DB-01）——直连是唯一通道；
- **App 端副本（必须）**：经直连传输至家长 App 的数据，其缓存与留存**应当**最小化；档案删除（C4）时**必须**使家长 App 端副本同步失效——S-06 删除级联的延伸。

## 9. 反模式

| ID | 反模式 | 严重程度 | 违反 |
| --- | --- | --- | --- |
| AP-DB-01 | 家长端经互联网云同步 / 中转（直连通道除外） | **高危** | 8 |
| AP-DB-02 | 推理调用发送非必要上下文（全量档案 / 隔离级记忆 / 审计日志） | **高危** | 7.2 |
| AP-DB-03 | 导出明文或无签名 | **高危** | 5.2 / 6.1 |
| AP-DB-04 | 导入验签失败部分接受 | **高危** | 6.1 |
| AP-DB-05 | 匿名遥测含可识别字段 | 严重 | 3.3 |
| AP-DB-06 | 性能不足时批量上传学情到云端计算（超出最小必要） | 严重 | 7.2 |
| AP-DB-07 | 未验证配对的直连接入被接受 | **高危** | 8 |

严重程度口径沿用反模式手册：**高危** = 合规红线 / 儿童数据外泄风险，评审一票否决。本表 5 个高危项与用例集 P0 用例一一对应（AP-DB-01→BD-07、AP-DB-02→BD-10、AP-DB-03→BD-02、AP-DB-04→BD-05、AP-DB-07→BD-09）。

## 11. 与既有文档的接口
