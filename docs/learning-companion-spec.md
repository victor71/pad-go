## 1. 目的与范围

本规范定义学习伴侣系统的三条主线行为准则：**主动沟通**（含话痨模式）、**知识储备驱动的兴趣预测**、**掌握度建模**，以及贯穿三者的安全伦理底线。

本规范刻意停留在"什么必须成立"的层面，不规定算法、架构与数据结构。技术选型（如何实现掌握度估计、如何做图邻接推荐等）在方案阶段另行设计，且任何方案**必须**通过本规范与两份反模式手册的合规评审。

## 3. 产品核心立场

以下四条立场是本规范的立法基础，后续所有条款由此推导：

1. **知识储备是唯一标尺**：儿童能学什么、对什么感兴趣，由其当前知识储备决定，**不由年龄和年级决定**。不存在"这个年级才能学"的内容。
2. **主动陪伴是核心形态**：学习伴侣必须主动与儿童沟通（含话痨模式），被动应答式的伴学不达标。
3. **使命是完善知识网络**：主动沟通的目的是帮助儿童不断完善知识点——补缺口、连孤点、强弱点，而非陪伴时长最大化。
4. **掌握度是第一等状态**：对知识点掌握程度的度量与运用是全系统的中心，推荐、复习、沟通选题、家长报告全部围绕它运转。

## 4. 术语定义

| 术语 | 定义 |
| --- | --- |
| 主动沟通 | Agent 不依赖儿童发起，自行开启话题、提问、反馈的行为 |
| 话痨模式 | 高频、丰富、主动发起占比显著的一档沟通风格，是正式产品形态而非缺陷 |
| 知识储备 | 儿童在稳定知识点编码（kp_code）空间上已确认掌握的知识集合 |
| 掌握度 | 单个知识点上的掌握程度估计，含置信度与时间戳 |
| 兴趣预测 | 依据知识储备与行为证据，预测儿童可能感兴趣的知识点 |
| 邻近发展区 | "已知之上一步"：由已掌握知识出发、经前置结构可达但尚未掌握的区间 |
| 探索性内容 | 儿童当前知识图谱之外的邻近领域内容，用于拓宽知识面 |

## 5. 主动沟通规范（含话痨模式）

### 5.1 使命锚定（必须）

话痨模式是正式产品形态，但主动发起的话题**必须**锚定于学习使命，锚点限于五类：

1. **知识缺口**：检测到未掌握/薄弱的知识点；
2. **知识连接**：可与新知识建立的关联（"你知道的那个火山，其实和这个有关系"）；
3. **掌握度变化**：进步、遗忘预警、复习时机；
4. **兴趣延伸**：从当前知识储备出发的邻近话题（含先前会话中儿童自发提问、尚未兑现的话题跟进——兑现按本锚点归类）；
5. **初始画像**：冷启动探测类话题（见 6.7），仅冷启动阶段合法，初始画像建成后该锚点退役。

关系维护性质的闲聊**可以**存在，但占比**应当**有界且可配置；纯娱乐性闲聊不得成为主动沟通的主成分。

### 5.2 时机与节奏（必须）

- 儿童处于专注作答或深度任务时**不得**主动插话，除非儿童求助或出现明显卡壳；
- **必须**尊重结束信号：儿童明确表示结束时当轮收尾，不得开启新话题拖延；
- 主动发起频率**必须**分档可调（如：安静 / 适度 / 话痨），儿童可自主选档，家长可设上限；安静档为最低限度主动（仅保留高价值锚点），任何档位**不得**退化为纯被动应答（第 3 节立场 2）。

### 5.3 挽留禁令（必须）

**禁止**一切以延长使用时长为目的的挽留设计：情感绑架（"你走了我会孤单"）、损失厌恶（"今天不学完勋章就没了"）、无限"再来一次"循环。产品北极星指标**不得**是使用时长或打开频次。

### 5.4 真实锚点（必须）

主动开口中涉及"上次 / 之前 / 你已经"的表述**必须**由真实检索到的记忆支撑，禁止编造记忆作为话头（反模式 AP-LC-13）。

### 5.5 适口性（必须）

主动沟通内容**必须**通过儿童适口性审查：不翻旧账、不做贬损性对比、不使用成人化或评判式表述（反模式 AP-LC-12）。

### 5.6 可审计（应当）

主动发起的时机、话题锚点、儿童接受/拒绝/无视的反馈**应当**留档，用于节奏与话题质量调优。

## 6. 知识储备驱动的兴趣预测规范

### 6.1 年龄与年级非门禁（必须）

- 任何学习内容、知识点、难度等级**不得**以年龄或年级作为解锁、限制或排序条件；
- 年龄、年级字段**不得**进入难度判定与兴趣预测的特征集；
- 唯一例外是法定合规与内容安全过滤（见 8.1），且该过滤独立于推荐逻辑运行。

### 6.2 知识储备为唯一难度标尺（必须）

内容的可及性由"当前知识储备 + 知识点前置结构"判定。判定结果**必须**可解释：因缺失哪些前置知识点而暂不可及，补充什么即可及。（目标成功率区间与难度升降机制见《压力与难度调节规范》）

### 6.3 邻近发展区（应当）

兴趣预测与推荐**应当**落在"已知之上一步"：从已掌握知识点出发，沿知识结构的邻接、因果、主题关联扩展；既不原地重复（AP-LC-23 茧房），也不跳崖冒进（AP-LC-22）。（压力目标区间与响应序列见《压力与难度调节规范》）

### 6.4 探索义务（必须）

推荐流与主动沟通选题**必须**包含探索性内容（知识图谱之外的邻近领域），防止兴趣茧房；两条通道的探索比例**必须**分别大于零、分别设有明确的配置下限，并纳入第 9 节验收清单。

### 6.5 个体化优先（必须）

兴趣预测**必须**基于该儿童自身的知识储备与行为证据；基于群体统计（同龄人喜欢什么、性别偏好等）的刻板推荐**不得**作为主策略（AP-LC-21）。

### 6.6 深度自适应解释（应当）

对儿童提出的问题，回答深度**应当**按其知识储备自适应调整，而非套用"年级标准答案"模板——同一个问题，对已有储备的儿童可以讲得更深。

### 6.7 冷启动规范（必须）

冷启动阶段（尚无知识储备数据时）**不得**以年龄、年级或群体统计先验填充知识储备与兴趣画像；**必须**通过主动探测（诊断性对话、自由探索引导）建立初始画像，初始估计一律为低置信度，并随首批证据快速翻转（AP-LC-04）。

## 7. 掌握度建模规范

### 7.1 第一等状态（必须）

掌握度是系统核心状态：推荐、复习调度、主动沟通选题、家长报告**必须**全部读取掌握度；掌握度更新**必须**触发下游策略刷新，形成闭环。只算不用的掌握度视为未实现（AP-LC-26）。

### 7.2 不确定性与时效（必须）

每个知识点的掌握度**必须**携带**置信度**与**时间戳**，随时间衰减、可被重新验证（引用记忆规范 7.3 / 7.4，反模式 AP-LC-02）；证据更新按来源置信度加权，不做全量记恨（AP-LC-03）。

### 7.3 多证据源（必须）

掌握度证据**必须**支持多源接入，至少包含：

1. 答题表现；
2. 对话中展现的知识（讲解、提问、纠错）；
3. 自发提及的知识；
4. 阅读 / 探索行为。

各证据源带可信权重，儿童口述类证据按 AP-LC-09 降级处理。

### 7.4 稳定挂载（必须）

掌握度**必须**挂在稳定的知识点编码（kp_code）上，支持教材改版与升学时的迁移（AP-LC-14）。

### 7.5 双通道呈现（必须）

- **对儿童**：以鼓励性、成长性语言呈现（"快掌握了""再练一次就稳了"），**禁止**原始分数、百分比、排名直出（AP-LC-27）；
- **对家长 / 教师**：可解释报告——哪些证据、何时产生、推出什么结论，支持逐条追溯（AP-LC-28）。

### 7.6 知识储备全景（必须）

系统**必须**能输出儿童当前知识储备的全景视图（每个知识点：已掌握 / 未掌握 / 待验证，附置信度与时间戳），作为第 6 章推荐、复习调度、5.1 主动沟通选题与 7.5 家长报告的统一输入；各消费端**不得**各自维护私有副本。

## 8. 安全与伦理底线

### 8.1 内容安全独立生效（必须）

内容安全分级与过滤是合规底线，**独立于**"不按年龄限制"原则运作：任何知识储备水平都不解锁不安全内容。本条不构成 6.1 的例外漏洞——安全过滤不判难度、不判兴趣，只拦不安全。内容安全过滤**可以**依据法规使用年龄参数，但仅限安全分级用途，其结果**不得**回流至难度判定与兴趣预测（6.1）。

### 8.2 反成瘾设计（必须）

主动沟通与话痨模式**不得**以最大化时长 / 频次为目标优化；**必须**支持家长设置的总量控制（单次 / 每日），触达上限时主动收尾并遵守。

### 8.3 推荐可解释（应当）

家长端**应当**能查看推荐依据（为什么推这个知识点），与 6.2 的可及性解释共用机制。

### 8.4 记忆与隐私

涉及儿童数据、多孩隔离、家长端标注隔离等，一律引用 `docs/agent-memory-system-spec.md` 第 8 节与 AP-LC-08 ~ 11，本文不重复立法。
