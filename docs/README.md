## 2. 阅读路径

- **新人上手**：伴学规范 §3（四条产品立场，全部文档的立法基础）→ 通用记忆规范 → 掌握度生命周期规范 → 架构主干 → Agent Loop 设计 → 用例集；
- **方案评审**：先过规范条款 → 对照反模式手册速查总表 → 跑用例集 P0 门禁组；
- **修订规范时**：同步检查用例集元规则（追溯矩阵双向完备）与反模式手册的违反条款映射；登记表只登记编号空间归属，不需要为他文档升版同步本文档。
