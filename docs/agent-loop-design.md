## 1. 目的与范围

产品有三个硬特点：学习围绕知识点、不设年级年龄门禁（伴学 6.1）；主动沟通是核心形态而非可选增强（伴学立场 2）；系统按年为单位长期运行。朴素的一层 `while: 感知 → 思考 → 行动` 循环在这三点上分别不成立：

1. **无边界**：不存在"下一步教什么"的默认顺序（课程表），每一步都是在（kp 图 × 掌握度投影）上的搜索决策；儿童的位置只能由证据推断（伴学 6.7），不能由对话上下文的模糊印象充当；
2. **主动**：纯输入驱动的循环在儿童不在场时永不运转，主动沟通无从发生——系统自治行为没有人类触发者（架构 2.3 注）；
3. **长稳**：上下文窗口与进程寿命都短于儿童的使用年限，一切以对话上下文为权威的设计必然腐烂。

本文的答案：**双唤醒源 + 装配式回合 + 状态完全外置**，组织为四个时间尺度递增的循环（环 A–D）。LLM 的自由裁量只存在于两处——环 A 的受限动作空间内、环 C 的单次开场起草调用；其余全部是确定性编排。

## 2. 设计公理（三条）

| # | 公理 | 推导自 | 运行时含义 |
| --- | --- | --- | --- |
| AX-1 | 世界模型在外部状态，不在上下文 | 无边界（伴学 6.1 / 6.3 / 6.7） | 每回合从投影与记忆**装配**决策上下文；"下一步教什么"是图上搜索（邻接 + 探索义务），不是查表 |
| AX-2 | 主动 = 第二唤醒源；时机决策与内容生成分离 | 主动沟通（伴学 5.1–5.3、5.6、8.2） | 调度事件与输入事件汇合于同一回合机制；**何时**开口由确定性策略判定（可审计、可预算、可测试），**说什么**由 LLM 生成 |
| AX-3 | 循环无状态，状态全外置 | 长稳（生命周期 2.2、架构 C1 / C2） | 循环组件可随时死亡重启；唯一事实源是证据日志（内核）；工作上下文不跨会话携带 |

## 3. 总体结构

### 3.1 结构图

```
唤醒源① 儿童输入事件 ──┐                     ┌────────────────────────────────────┐
                      ├─► 环 B 会话环 ─► 环 A 回合环 │ 状态层（架构主干 L3–L5，唯一权威）        │
唤醒源② 调度事件 ──► 环 C 主动环 ──点火─┘        │ 证据日志(内核) ─f()→ 投影/全景(外环)      │
 （到期/上游遗忘/重激活/  （小时–天级）           │ 记忆库(内核) · 检索服务(K3)              │
  评估唤起/拓展候选就绪）                        │ 同意/审计(内核) · 配置 · 时钟             │
                                               └────────────────────────────────────┘
            环 D 巩固环（天级，闲置/充电窗口）：重放自比对 · 记忆巩固 · 节奏复盘 · 版本重算
```

四个环共用同一状态层与四收口点：写证据只经证据网关（K1）、写记忆条目只经记忆写入器（K7）、读记忆只经检索服务（K3）、外发只经推理网关（K4）。**循环层没有自己的收口点，也没有自己的内核存储**（LD-9）。

### 3.2 环 ↔ 编排组件映射

| 环 | 时间尺度 | 唤醒 | 对应 L2 组件（架构 3.2） | 承载用例 |
| --- | --- | --- | --- | --- |
| 环 A 回合环 | 秒级 | 儿童输入 / 环 B 派发 | 会话编排器（回合驱动） | UC-03 / UC-05 |
| 环 B 会话环 | 分钟级 | 儿童开始 / 环 C 点火 | 会话编排器（会话生命周期） | UC-02 / UC-05 / UC-07 |
| 环 C 主动环 | 小时–天级 | 调度事件 | 主动沟通编排器 + 探针调度器 + 任务调度器 | UC-04 / UC-06 / UC-09 |
| 环 D 巩固环 | 天级 | 闲置/充电窗口 | 重算引擎 + 遗忘策略 + 容量治理 | UC-17 / UC-19 |

环不是新组件：环 A / B 是会话编排器的两个职责面（回合驱动 / 会话生命周期），环 C 是三个自治编排组件的事件驱动运转形态，环 D 是后台维护任务的时间窗口组织。

### 3.3 LC-1 唤醒契约

- **前置**：唤醒事件（两类之一）
- **后置**：事件被消费或显式推迟（留队），永不静默丢失
- **不变量**：
  1. 唤醒源封闭为两类：**输入事件**（儿童发言 / 操作）与**调度事件**——枚举：时效到期、上游遗忘传播、重激活、评估唤起（生命周期 3.2 / 8）、拓展候选就绪（本文 8.4）、内容包挂载、闲置充电窗口；
  2. 调度事件全部由状态层派生量产生（时钟到期、投影迁移、候选队列就绪），循环层不得自造触发源；
  3. 事件消费继承架构 6.1 任务优先级（证据写入 > 投影增量 > 探针 > 索引 > 重算）；
  4. 任何环的执行不得阻塞证据写入路径。
- **否证**：M-09 / M-20 / M-23（探针调度侧）+ 第 11.3 节待增拓展用例

### 3.4 编排器逻辑（示意）

```text
on 输入事件(msg):                              # 唤醒源①
    turn_loop(环B.当前或新建会话(), msg)

on 调度事件(ev):                                # 唤醒源②
    if ev.类型 == 闲置充电窗口: 环D.tick(); return
    if not 闸门.可通过(ev): 事件.推迟留队(); return       # 环 C 三道闸（6.2）
    if ev.需对话开场:                                    # 主动沟通类（含窗口④ 拓展发起）
        opening = LLM起草(ev.锚点, 检索服务.recall(ev))    # 单次调用，经 K3 / K4
        通道.发送(适口性审查(opening))
        沟通反馈留档(ev, opening)                         # 伴学 5.6
    else:                                               # 探针 / 诊断类
        探针调度器.submit(ev)                            # 走既有 UC-09 全部规则

def turn_loop(会话, msg):
    for step in range(回合上限):
        ctx = 装配上下文(会话, msg)                       # LC-2：装配，不堆积
        动作 = 策略层.合法动作集(ctx) → LLM 在集合内选择并生成  # LD-2 / LD-4
        结果 = 执行(动作)                                 # 出题 / 判题 / 图谱查询 / 呈现
        落锚(结果, msg)                                   # 证据(K1)/记忆候选(K7)/反馈留档，至少其一
        if 会话.应当结束(): 环B.收尾(会话); break          # 结束信号 / 预算 / 疲劳前兆
```

## 4. 环 A：回合环

唯一存在 LLM 主动推理的环。每回合六拍：

1. **理解**：儿童输入的意图（求助 / 展示 / 闲聊 / 求答）与知识信号（展现了什么、自发提及了什么）——语义提取走智能级队列，结果按证据源 2 / 3 经证据网关入日志（AP-LC-09 降权），记忆候选经 K7；
2. **定位**：当前话题映射到 kp 子图，读该子图投影快照（含水平 / 时效 / 置信）；
3. **决策**：策略层给出本轮**合法动作集**（讲解 / 提问 / 探针 / 回应 / 收尾；难度带；锚点配额——含拓展类配额，8.4 窗口②），LLM 在集合内选择并生成语言；讲解深度按该 kp 的 μ 与邻域自适应（伴学 6.6）；
4. **执行**：工具调用（出题 / 判题 / 图谱查询 / 呈现）；
5. **落锚**：证据 append → 投影增量更新；触发的时效迁移、遗忘传播事件入队给环 C；
6. **越界检查**：适口性审查（无翻旧账 / 贬损 / 编造记忆）、安全过滤、挽留话术检查（伴学 5.3–5.5）。

**落锚纪律**：每个完成的回合至少留下一条持久痕迹——证据（K1）、记忆候选（K7）或沟通反馈留档（UC-06 既有日志）——三者皆无的回合视为未发生（可审计性的回合级表达）。

### LC-2 上下文装配契约

- **前置**：会话上下文 + 当前输入
- **后置**：一次完整的最小必要推理载荷（接架构 M3 第 4 步）
- **不变量**：
  1. 回合上下文 = 人格规格（静态指令）+ 会话目标（环 B 给定）+ 相关 kp 子图投影快照 + 检索记忆条目（经 K3，带时间戳）+ 档位与预算余量 + 当前会话最近 N 轮（截断）；
  2. **工作上下文不跨会话携带**：历史会话只以经 K3 检索的记忆条目形式进入新会话，禁止把上一会话的对话原文或其摘要当作默认前缀注入；
  3. 组装经推理网关（K4），禁发清单校验与逐调用审计照常生效；记忆类表述必须能关联到检索审计记录（UC-05 扩展流 6b）；
  4. 装配产物中，kp 子图投影快照与档位/预算状态以**系统指令**槽位进入推理载荷（部署 7.2 三枚举之一），属最小必要上下文（架构 C4），不构成新的外发类别。
- **否证**：C-05 / R-01 / BD-10（沿用 UC-05 验收）

## 5. 环 B：会话环

持有会话小目标（本会话服务于哪类锚点，如"探测分数加法缺口"），职责：

- **开场第一拍**（投放窗口①，8.4）：检查悬念缺口登记，有未兑现的自发提问则优先兑现——"上次你问的 X，我找到答案了"；
- **双信号监控**：认知信号（连续失败、掌握度估计漂移）接响应序列（压力 7.1）；压力前兆信号（压力 8.1 / 8.2）接过载窗口处置——窗口内降节奏、推迟探针、失败证据标记"受状态受限"；
- **结束纪律**：儿童明确结束 → 当轮收尾（伴学 5.2）；触达家长总量控制 → 主动收尾并遵守（伴学 8.2）；无挽留话术（伴学 5.3）；
- **收尾动作**：上下文压缩 → 会话摘要（source = 会话摘要，经 K7 写入门槛）；证据已在回合内实时写完，收尾不补写教学证据。

## 6. 环 C：主动环

事件驱动的常驻调度，儿童不在场时照常运转（宿主休眠策略随 Host SPI，属部署层）。信号源全部来自状态层：到期重验、上游遗忘传播、重激活、评估中唤起、初始画像探测（仅冷启动）、悬念缺口 / 兴趣延伸就绪（第 8 章）。

**三道闸**（按序检查，任一不过则事件推迟留队）：

1. **预算与总量**：当日主动发起次数与家长总量控制（伴学 8.2；探针预算同源，生命周期 9）；
2. **专注 / 安静守卫**：专注作答或深度任务中不发起（伴学 5.2；UC-06 扩展流 0a）；
3. **档位与频控**：沟通档位（安静 / 适度 / 话痨，儿童可选、家长设上限）与主题域频控（8.3）。

**锚点优先级**：到期复习（当前学习路径上）> 知识缺口 > 拓展类（兴趣延伸 / 知识连接）> 关系维护闲聊（占比有界，伴学 5.1）；全部叠加 aging（生命周期 9 同款），防低优先级锚点长期饿死。

**两段式决策**：确定性规则层先筛（闸门 + 优先序 + 时机窗口）→ 通过的候选交 LLM **单次起草**开场白（带检索记忆支撑，经 K3 / K4）→ 适口性 + 安全过滤 → 发出 → 接受 / 拒绝 / 无视反馈留档（伴学 5.6，节奏复盘的原料）。

**离线行为**：智能级不可用时主动沟通**一律不发起**（部署 2.5 智能级暂停）——调度事件推迟留队，联网后按事件时间重评时机；不排网补发（开场白过期即失效），不启用本地模板开场。

## 7. 环 D：巩固环

天级后台任务，安排在闲置 / 充电窗口（与架构 6.1 重算窗口同源），职责：

1. **重放自比对**：物化投影 vs 重放结果一致性断言常态化（架构 5.4，X-01 机制的周期化执行）；
2. **记忆巩固**：遗忘策略 TTL / 衰减扫描、容量淘汰（K7 淘汰序）、互补记忆合并建议；
3. **节奏复盘**：消费沟通反馈留档（伴学 5.6），统计各类锚点接受率，产出**调档建议**（呈现给家长端，伴学 8.3 同款可解释机制）与频控 / 冷却参数的自适应调整（有界、可配、可回退）；**档位本身仅儿童与家长可改**（伴学 5.2），系统不自调档位；
4. **版本重算**：元数据版本升级触发全量重放（M6），差异聚合为诊断小节。

## 8. 拓展型主动：知识面拓展机制

### 8.1 定位

"根据会话历史与知识点关联性，主动帮助儿童拓展知识面"是伴学 5.1 锚点 2（知识连接）与锚点 4（兴趣延伸，含未兑现提问跟进）的运行时落地，同时把伴学 6.4 探索义务从推荐流扩展到主动沟通选题通道（本次修订同步落法，伴学 v1.19）。**图内扩展是深化，图外探索才是拓宽**——两类候选并存，探索比例两通道分别设下限。

启用前置：初始画像已建成（锚点 5 退役后）。冷启动期的探索义务由探测环节自然承担（伴学 6.7），不启用本机制。

### 8.2 钩子抽取（会话历史 → 候选原料）

会话收尾压缩时（环 B），从对话流抽取三类结构化信号：

| 信号 | 识别特征 | 处置 |
| --- | --- | --- |
| 知识触点 | 对话中展现 / 提及、可映射到 kp 的内容 | 即证据源 2 / 3，已按 AP-LC-09 权重入日志；候选派生读投影 |
| 兴趣火花 | 自发追问、同会话重复回到、情绪高涨的话题 | 证据源 3 入日志；信号分级（自发追问 > 顺带提及 > 被动应答）供候选派生读取 |
| 悬念缺口 | 儿童问了但未展开、被搁置的问题 | **显式登记**：问题原文 + 会话引用（证据指针）+ 时间戳；兑现后出队 |

抽取由 LLM 完成 kp 归一（映射不上 → 归入图外主题域）与信号分级；抽取结果本身按证据规则落盘（信号是观察，不是推断落盘——推断在读取层进行，生命周期 2.3-2）。

### 8.3 候选生成（图上双向扩展）

**桥接候选（图内）**：沿 `supports` / `relates_to` 边走 1–2 步（知识契约 4.1 消费矩阵：这两类边只服务推荐，不做门禁、不参与传播——**拓展永远不能长出"必须学"的牙齿**）。打分 = 关联强度 × 目标 kp 枢纽度 × 未覆盖度。**防跳崖校验**：目标 kp 的"桥 kp 集合"（儿童已掌握、足以把新话题讲到入口的支点）非空才可投放；为空则不投放，可及性解释与伴学 6.2 共用机制（"沿什么边、从哪座桥过来"）。

**探索候选（图外）**：锚点所在主题域的邻近领域，来自关联库（source 纪律同知识契约 4.2：教研确认 / 规则导出 / 模型推断，推断来源降权只作推荐）；安全分级是图外内容唯一门禁（伴学 8.1）。

**全局约束**：

- **防茧房（AP-LC-23）**：按关联强度采样而非恒取 top-1；两通道探索比例分别有配置下限（伴学 6.4）；
- **频控**：同一主题域带冷却窗口；儿童连续轻应或拒绝 → 冷却自动加长（有界、封顶可配）——"火山追着孩子跑三个月"是本机制的头号死法；
- **占比上限**：拓展类在主动发起总量中设占比上限，防"天天安利新知识"的推销员形态。

### 8.4 投放窗口（四梯级）

| 窗口 | 投放时机 | 决策归属 | 打扰成本 | 最适候选 |
| --- | --- | --- | --- | --- |
| ① 开场兑现 | 会话第一拍 | 环 B | **零**（儿童已在会话中） | 悬念缺口：先前未兑现的自发提问 |
| ② 顺势延伸 | 对话自然间隙（求助后 / 反馈拍 / 闲聊拍） | 环 A（合法动作集内，占锚点配额） | 极低 | 强信号兴趣火花，桥一步可达；专注作答中禁插（伴学 5.2） |
| ③ 会话尾播种 | 收尾模板槽位 | 环 B | 低 | 下次会话钩子（预告不展开）："下次跟你说 X 和它的关系" |
| ④ 跨会话发起 | 环 C 调度 | 环 C | 高（占主动预算与打扰额度） | 冷却后的兴趣延伸（距上次会话 1–3 天窗口择机）；其余候选的兜底 |

**投放纪律（LD-5）**：同一候选按 ①→②→③→④ 顺序寻找可用窗口，**能用低打扰窗口消化就不用高打扰窗口**；窗口④ 只兜两类——冷却后值得重燃的强兴趣、长间隙后的关系维护。窗口④ 的拓展类候选在环 C 优先序中默认低于到期复习与缺口类，aging 同样适用。

### 8.5 LC-3 拓展发起契约

- **前置**：已通过三道闸与投放窗口检查的拓展候选
- **后置**：开场白发出且反馈留档；或显式不发起（原因留痕）
- **不变量**：
  1. **桥梁三件套齐备才可生成**：(a) 真实记忆引用——必须关联到检索审计记录（伴学 5.4，反编造）；(b) 桥——从儿童已掌握知识点到新话题的显式连接（锚点 2 本体）；(c) 低门槛钩子——一个儿童答得上来的问题或一个惊奇事实；
  2. **姿态红线**：入口永远是"分享惊奇"，禁止任务化表述（"你还差三个知识点"）、进度压力与挽留话术（伴学 5.3）；
  3. 生成路径同 M3：检索服务（K3）→ 推理网关（K4）→ 适口性审查；LLM 仅负责把三件套织成语言，不负责选择时机或话题；
  4. 频控与占比上限在生成前检查（三道闸第三闸）。
- **否证**：C-02 / C-04 / C-06 沿用 + 第 11.3 节待增用例

### 8.6 反馈闭环

儿童反应分四级——**深入 / 轻应 / 拒绝 / 无视**，分别写回：

| 写回对象 | 载体 | 说明 |
| --- | --- | --- |
| 兴趣域强度 | 投影（外环） | 挂粗粒度主题域（非 kp 级），由证据源 3 / 4 证据派生，低权重累积、随时间衰减——供伴学 6.5 个体化兴趣预测读取 |
| 节奏档案 | 沟通反馈留档（伴学 5.6） | 各锚点类接受率 → 环 D 节奏复盘 → 调档建议与频控自适应 |
| 桥通行率 | C5 匿名诊断通道（默认关） | 某 kp→kp 桥被走过且深入的比例，属部署 3.3"聚合指标"类——仅 C5 同意开启时以不可逆识别形态聚合上报；未开启时通道不生效，桥质量评估退化为教研侧内容包迭代。**不上儿童档案**（跨档案统计不回流个体，伴学 6.5） |
| 若深入 | 证据网关（K1） | 目标 kp 首批证据，低置信、评估中起步（生命周期 8.1 投影）；探索期难度按压力 4.1 目标成功率档位，刻意偏难的失败不降级不排针（生命周期 6） |

### 8.7 状态归属与重建（架构禁区 2 的遵守声明）

拓展机制引入的调度状态全部**外环化**，无新增内核：

| 状态 | 归属 | 重建规则 |
| --- | --- | --- |
| 兴趣域强度 | 投影（外环） | f(证据日志) 重放 |
| 拓展候选队列 | 策略层调度缓存（外环） | 由（证据源 2 / 3 证据 + 悬念缺口登记 + 投影）重扫重建；丢失后果为功能性退步（部分候选晚到），无真相损失 |
| 悬念缺口登记 | 调度队列条目（外环），锚为已落盘的提问证据 | 由（未兑现的自发提问证据 − 兑现事件）重放重建；入队 / 出队事件留审计 |
| 频控 / 冷却参数 | 配置层 | 有默认值，禁止硬编码（架构 3.2 配置组件纪律） |

## 9. 长稳运行工程

| 敌人 | 防护 | 落点 |
| --- | --- | --- |
| 上下文腐烂（越聊越歪） | 装配式上下文；工作记忆不跨会话；历史只经 K3 检索进入 | LC-2 |
| 状态漂移 | 证据日志唯一事实源 + 投影版本标记 + 环 D 重放自比对 | 架构 C1 / 5.4 |
| 行为漂移（换模型后人设变了） | 人格是规格数据；教学决策与时机决策确定性化；LLM 为可替换组件 | LD-2 / LD-8 |
| 成本失控 | 双预算闸：每日探针数（生命周期 9）+ 每日主动发起与 token 预算（伴学 8.2 同源） | 环 C 三道闸 |
| 打扰疲劳 | 优先序 + aging + 主题域频控 + 接受率复盘 | 6 / 8.3 / 8.6 |
| 进程死亡 | 循环无状态；证据日志 WAL + 幂等 → 重启即重新装配 | 架构 6.1 |
| 数据年限成长（用五年） | 元数据版本化 + 全量重放（M6）；调度状态外环化随版本重算 | 环 D |

**降级链**（对架构 6.2 失效模式表的循环层补充）：云端 LLM 不可达 → 对话降级、作答证据照常（既有）；窗口④ 推迟留队（6）；环 D 跳过本窗口顺延；检索未命中 → 开场白不得含记忆性表述（UC-05 扩展流 3a 同款约束）。

## 10. 设计决策与禁区

### 10.1 设计决策（LD-1 ~ LD-9）

| # | 决策 | 理由 | 被否决的替代 |
| --- | --- | --- | --- |
| LD-1 | 双唤醒源，调度事件与输入事件汇合于同一回合机制 | 主动沟通是核心形态（伴学立场 2）；自治行为无人类触发者 | 纯输入驱动（主动无从发生）；独立"主动 Agent 进程"（两套回合机制，行为漂移） |
| LD-2 | 时机决策与内容生成分离：何时 / 对谁 / 何锚点为确定性代码，说什么为 LLM | 时机是安全攸关、预算攸关决策，需可审计（5.6）、可预算（8.2）、可测试 | LLM 自由裁量时机（不可审计、不可回归测试） |
| LD-3 | 回合上下文装配不累积 | 防上下文腐烂；与 K4 最小必要同构 | 长对话历史滚动携带（成本与漂移都失控） |
| LD-4 | LLM 只住环 A（+ 环 C 单次起草、语义提取），不采用多智能体协商 | 儿童产品行为一致性、可测试性、成本可控优先于能力上限 | Agent 社会 / 多智能体会话（行为不可回归、成本不可预算） |
| LD-5 | 拓展投放窗口梯级 ①→④，低打扰优先；窗口④ 拓展类默认排复习与缺口之后 | 打扰成本阶梯化；学习闭环（补缺口防遗忘）优先于开新面（伴学立场 3） | 全部经主动环发起（打扰额度挤占复习）；拓展优先（本末倒置） |
| LD-6 | 拓展候选只走 `supports` / `relates_to`，桥接 1–2 步 | 知识契约 4.4 消费矩阵；拓展不做门禁、不参与传播 | 沿 `requires` 拓展（长出"必须学"的牙齿） |
| LD-7 | 防跳崖 = 桥 kp 集合非空校验；防茧房 = 关联强度采样 + 探索下限 | AP-LC-22 / 23 的机制化 | 恒取最强关联（茧房）；跳多步（跳崖） |
| LD-8 | 人格 = 规格数据；模型升级不迁移行为权重 | 长稳：模型换代不改变系统行为基线 | 用微调承载人格（绑定模型版本，不可审计） |
| LD-9 | 拓展调度状态全部外环化，证据为锚 | 架构禁区 2（策略层不持久化状态）；队列丢失无真相损失 | 策略层自建持久存储（旁路状态层） |

### 10.2 循环层禁区

1. 主动发起的时机、锚点、频控决策不得交 LLM 自由裁量（LD-2）；
2. 工作上下文不得跨会话携带，历史会话不得以未检索的原文形式进入新会话（LC-2）；
3. 拓展候选不得参与难度门禁与图传播，不得以未掌握前置为由回绝儿童的自发提问（LD-6；提问走对话通道不受门禁）；
4. 不得无视连续拒绝 / 轻应信号对同一主题域持续发起（8.3 频控）；
5. 环 D 的节奏复盘不得直接改档位（档位仅儿童与家长可改，伴学 5.2）；
6. 任何环不得在证据写入路径之外写证据、不得绕过 K3 / K4 / K7 收口点（复述架构禁区 1，循环层同样受约束）。
