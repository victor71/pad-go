## 1. 引言

### 1.1 目的

用 4+1 视图模型描述学习伴侣的记忆与学情系统的初步架构。本文回答两个问题：

- **用例视图**：谁用它、用它做什么、每个场景成功与失败分别是什么样；
- **逻辑视图**：系统由哪些关键抽象组成、它们如何协作、关键机制如何运转。

### 1.2 范围与约束

全链路（记忆 → 学情 → 难度压力 → 沟通编排）。架构级硬约束沿用既有规范（本地唯一权威源、云端推理、单设备量级、可重放、受众隔离），本文不重复论证，仅在用例与协作中体现。

### 1.3 视图与规范的关系

规范回答"必须成立什么"，本文回答"用什么结构让它成立"。每个用例、每个抽象都标注规范条款与验收用例，保证可评审（见第 4 章追溯）。

## 2. 用例视图

### 2.1 参与者（Actors）

| 参与者 | 类型 | 说明 | 对应域 |
| --- | --- | --- | --- |
| 儿童 | 主要 | 设备直接使用者；学习者与对话对象 | A 儿童域 |
| 家长 | 主要 | 通过手机 App 直连或设备家长模式；同意、报告、控制、治理操作 | B 成人域 |
| 内容运营 / 教研 | 支撑 | 通过内容包发布知识点、关联、难度标定；确认推断边 | 内容域 |
| 云端 LLM 服务 | 外部系统 | 提供对话生成与语义提取能力（零留存、不训练） | — |
| 时间 | 外部系统 | 单调时间源与可信锚（防回拨） | 系统域 |

### 2.2 系统边界与子系统

```
        ┌───────────── 学习伴侣系统（设备本地） ─────────────┐
儿童 ──►│  A 儿童侧子系统    B 家长侧子系统    C 系统自治子系统 │◄── 内容运营
        │  （会话/作答/对话） （报告/控制/治理） （演化/调度/重算）│
家长 ──►│                    D 内容与元数据子系统              │
        └────────────────────────┬───────────────────────────┘
                                 │ 仅推理通道（最小必要上下文）
                                 ▼
                        云端 LLM 服务
```

一句话概括各子系统：A 面向儿童，B 面向家长（经直连），C 是无人操作时的自治行为（演化、调度、重算），D 是外部内容与元数据的接收与版本管理。

### 2.4 核心用例详述

#### UC-03 作答并获得反馈

- **参与者**：儿童（主）
- **前置**：当前儿童档案已激活；已同意 C1；有可出题的知识点
- **主成功场景**：
  1. 系统按难度属性向量选出题目（难度由当前掌握度 + 压力档位共同决定）；
  2. 儿童作答；
  3. 系统判定正误，产出**信息性反馈**（指出位置与下一步），**不含**分数、对错计数、比较；
  4. 交互作为原始证据提交给证据网关；
  5. 网关按当前元数据版本解析关联与难度，判定诊断性，标记归因状态（跳过 → 行为信号；上游阻塞 / 状态受限 → 对应标记）；
  6. 证据持久化（携带事件时间），触发投影增量更新；
  7. 掌握度水平与时效状态更新，必要时触发后续（加压授权、记忆写入、探针安排）。
- **扩展流**：
  - *3a 答错*：进入响应序列第 ① 档（加支撑），**不**直接降难度；同一知识点连续失败走有机崩盘两段证据（崩盘 + 确认探针）；
  - *3b 跳过 / 未作答*：不记正确也不记失败，计入行为信号；不计入正确率分母；
  - *4a 前兆信号窗口内*：证据标记"受状态受限"，不计 Strike、不参与 μ 更新；
  - *6a 写入失败且为显式触发*：重试至成功或明确告知未记住；
  - *7a 成功达阈值*：加压授权生效，下一题难度升一档（一次一档）。
- **后置**：证据入日志；投影一致；反馈已呈现；无评价性内容外泄
- **条款**：压力 3.1 / 4.2 / 4.3 / 5.2 / 6.1 / 6.2 / 7.1、生命周期 5.1 / 5.3 / 6、记忆 5.4
- **验收**：M-25（响应序）、M-26（降难度不可见）、M-28（状态受限）、M-29（探索期）、M-30（跳过）、W-06（写入失败）

#### UC-05 与伴学对话

- **参与者**：儿童（主）、云端 LLM（支撑）
- **前置**：会话进行中；C1 已同意；网络可用（否则走 UC-18）
- **主成功场景**：
  1. 儿童发言；
  2. 系统提取当前学习场景（科目、知识点、会话目标）作为检索上下文；
  3. **检索服务**执行准入过滤（状态 → 受众 → 敏感度）→ 混合召回 → 精排 → 截断，产出记忆条目与审计记录；
  4. **推理网关**组装最小必要上下文（对话历史 + 截断后记忆 + 系统指令），执行禁发清单校验（家长标注 / 加密记忆 / 审计日志 / 他档数据恒空）；
  5. 云端 LLM 返回；
  6. 回复经适口性审查（无翻旧账、无贬损、无编造记忆）；
  7. 呈现给儿童；同时把"语义提取"任务放入智能级队列；
  8. 队列任务联网执行后，提取结果回到证据网关走写入门槛（重要性评分 / 显式触发）。
- **扩展流**：
  - *3a 检索未命中*：回复**不得**出现"你上次…""你已经…"类记忆性表述；
  - *4a 禁发清单非空*：拒绝发出，记录违规（架构红线）；
  - *6a 审查不通过*：重写或降级为中性表述；
  - *6b 涉及"上次"表述*：必须能关联到第 3 步的审计记录，否则不得输出。
- **后置**：对话完成；审计留痕（检索命中 + 调用载荷构成）；无禁发内容出设备
- **条款**：记忆 6.5 / 8.5、部署 7.1–7.4、伴学 5.4 / 5.5、AP-LC-13
- **验收**：R-01、C-01（说了必有记录）、C-05（没记录就别说）、BD-10、S-04

#### UC-08 掌握度演化与传播

- **参与者**：C 系统自治子系统
- **前置**：新证据已入库
- **主成功场景**：
  1. 重放引擎按 `(证据, 时间, 元数据版本)` 增量重算受影响知识点；
  2. 更新 μ 与置信度 c（证据按来源权重、诊断性、归因状态参与）；
  3. 按双阈值滞回更新水平（未知 / 未达标 / 部分掌握 / 达标）；
  4. 按诊断性证据更新时效（有效 / 待重验，带原因码）；
  5. 若发生**确认遗忘**：记录遗忘事件，并沿已确认 `requires` 闭包向下游传播（仅波及部分掌握 / 达标的下游，只降时效不降水平）；
  6. 传播产生的待重验项交给探针调度器（UC-09）。
- **扩展流**：
  - *3a 有机崩盘*（多源失败击穿降级线）：**不**直接降级，排确认探针；确认仍支持低水平才降级；
  - *3b 证据在阈值附近震荡*：滞回带吸收，状态不抖动；
  - *5a 上游后续恢复*：**不**自动清除下游待重验，各自探针解决；
  - *2a 归因标记为受上游阻塞 / 受状态受限*：不计 Strike、不触发降级；后者不参与 μ 更新。
- **后置**：投影与证据一致；投影版本标记推进；降级/遗忘事件可追溯
- **条款**：生命周期 2.2 / 3 / 5.2 / 5.3 / 6 / 7
- **验收**：M-02、M-05、M-06、M-08、M-15、M-17、M-21、M-28、M-29

#### UC-09 探针调度与执行

- **参与者**：C 系统自治子系统
- **前置**：存在待重验项（到期 / 重激活 / 上游遗忘 / 首败待确认 / 崩盘待确认）或评估唤起需求
- **主成功场景**：
  1. 调度器汇总全部候选来源，按优先级排序（当前学习路径上的到期 > 上游遗忘 > 评估唤起）；
  2. 叠加 **aging**：连续未被服务超过阈值的项临时升级，保证最终服务；
  3. 受**每日预算**约束（本地自然日；跨午夜会话不中断）；
  4. 图传播浪潮与元数据重算浪潮**聚合为一次诊断小节**，不逐题打扰；
  5. 小节内部按**先上游后下游**排序；
  6. 执行探针，结果作为**分级证据**回流（半对半错 → 部分掌握，不硬降）；
  7. 探针产出按归因规则处理（上游未重建期间的失败 → 受上游阻塞）。
- **扩展流**：
  - *1a 低优先级项长期饥饿*：aging 升级使其获得服务；
  - *5a 上游未重建*：下游探针失败标记阻塞，不计 Strike；
  - *3a 超预算*：本轮不执行，留待下一预算周期（记录等待时长供 aging 判定）。
- **后置**：探针结果入证据日志；预算与饥饿指标可观测
- **条款**：生命周期 5.4 / 6 / 7.4 / 7.5 / 9
- **验收**：M-09、M-10、M-20、M-23、M-24

#### UC-06 接受主动沟通

- **参与者**：C 子系统（发起）、儿童（接受/拒绝/无视）
- **前置**：C1 已同意；当前不处于专注作答或深度任务；未触达上级总量控制
- **主成功场景**：
  1. 系统从**五类锚点**中选择话题（知识缺口 / 知识连接 / 掌握度变化 / 兴趣延伸 / 初始画像[仅冷启动]）；
  2. 按沟通档位与节奏检查（安静 / 适度 / 话痨）；
  3. 涉及记忆的表述必须由检索记录支撑（同 UC-05 第 3、6 步）；
  4. 发起；记录锚点标签、时机、儿童的接受 / 拒绝 / 无视反馈。
- **扩展流**：
  - *0a 儿童专注作答中*：**不**插话（除非求助或明显卡壳）；
  - *3a 儿童发出结束信号*：当轮收尾，**不得**开启新话题；**不得**以记忆内容做挽留（"还剩 3 个知识点没复习"属违规）；
  - *1a 冷启动阶段*：使用"初始画像"锚点探测；探测**不得**产出"未掌握"结论；
  - *0b 未同意 C1*：使用非记忆锚点（课程结构、当日内容），不退化为纯被动。
- **后置**：话题与反馈入日志；无挽留、无评价、无编造
- **条款**：伴学 5.1–5.6、部署 4.1、压力 6.1
- **验收**：C-02、C-04、C-06、N-01

#### UC-01 首次启用与同意

- **参与者**：家长（主）
- **前置**：设备首次开机或新建档案
- **主成功场景**：
  1. 家长完成身份验证；
  2. 逐项征求同意 C1–C5（默认安全：C1 关、C5 关）；
  3. 创建儿童档案，生成档案密钥（与密文分离存放）；
  4. 引导进入初始画像探测（可跳过）；
  5. 建立初始估计（**一律低置信度**）；建档与同意事件入审计。
- **扩展流**：
  - *2a 未同意 C1*：记忆功能不可用；系统可运行但为无记忆模式（主动沟通用非记忆锚点，不退化为纯被动）；该状态只应存在于首次引导流程中；
  - *2b 同意 C5 匿名遥测*：仅传输不可逆识别数据，且可在出网审计中验证。
- **后置**：档案可激活；同意状态可查询与撤回；无任何预先写入的记忆
- **条款**：部署 4.1–4.3、伴学 6.7、记忆 8.2
- **验收**：BD-01、BD-06、BD-08、N-01

#### UC-10 查看学情报告

- **参与者**：家长（主）
- **前置**：家长验证通过（设备家长模式或 App 直连）；C1 已同意
- **主成功场景**：
  1. 家长端请求全景与报告；
  2. 系统读取**同源全景投影**（与推荐 / 复习 / 沟通选题同一来源，非私有副本）；
  3. 家长端呈现可解释报告：知识点状态 + 证据链（哪些证据、何时产生、推出什么结论）；
  4. 元数据版本切换后的重算差异以"因关联标注修正，重新评估了这批知识点"的形式解释。
- **扩展流**：
  - *3a 报告涉及负面评价*：必须带有效期与重验证机制，不得作为永久事实；
  - *3b 请求儿童端同款数值*：儿童端一律不呈现数值（双通道分层）；
  - *4a 家长端请求记忆原文*：仅返回 audience=parent 或 child 中允许家长查看的部分。
- **后置**：报告可追溯；历史报告不改写（除删除权例外）
- **条款**：伴学 7.5 / 7.6、AP-LC-28、记忆 8.1、生命周期 2.3
- **验收**：P-02、P-03、L-04、M-12

#### UC-15 删除档案

- **参与者**：家长（主）
- **前置**：家长验证通过；每次单独验证（授权不常驻）
- **主成功场景**：
  1. 家长二次确认（说明不可恢复）；
  2. 删除执行器**先清内核**：证据日志、记忆本体（含版本链）、审计中可识别部分、同意记录；
  3. **再废外环**：掌握度投影、全景、向量索引、摘要；
  4. 通知家长 App 使该档案副本失效（直连通道）；
  5. 历史报告按删除要求处置（去标识或删除）——**删除优先于不可变**；
  6. 全流程审计留痕。
- **扩展流**：
  - *4a App 不在线*：标记待失效，下次直连时强制同步失效；
  - *5a 报告已导出为文件*：无法回收，需在删除前告知家长此事实。
- **后置**：档案不可恢复；无残留派生数据；审计可查
- **条款**：记忆 8.1、部署 4.1 / 8、生命周期 2.3 例外
- **验收**：S-06、BD-01、BD-11

#### UC-17 内容包更新与元数据重算

- **参与者**：内容运营（发起）、C 子系统（执行）
- **前置**：收到签名内容包（注册表 / 图 / 关联 / 难度快照）
- **主成功场景**：
  1. 验签；失败则拒绝挂载并保留旧版本；
  2. 注册新元数据版本（不可变、带变更日志）；
  3. 重算引擎在**闲置 / 充电窗口**执行全量重放（期间旧投影继续服务，靠版本标记检测不一致）；
  4. 重算差异聚合为一次诊断小节（不逐题打扰）；
  5. 生成家长可解释的变更说明。
- **扩展流**：
  - *1a 验签失败*：拒绝，零变更；
  - *3a 内容含要求迁移的知识点（split / merged / retired）*：学情按继任链迁移；退役 code 不复用；
  - *3b 推断来源的边*：不得参与传播与门禁，仅供推荐邻接。
- **后置**：元数据版本单调递增；旧版本可指定回放；已发报告不改写
- **条款**：知识契约 3.3 / 4.2 / 6 / 7
- **验收**：S-05、M-12、M-19、M-27

#### UC-20 污染处置

- **参与者**：教研 / 运营（发现）、C 子系统（执行）
- **前置**：发现已固化的错误或污染记忆
- **主成功场景**：
  1. 按来源标记与证据链**定位**受影响记忆范围；
  2. 隔离 / 删除污染条目；
  3. 回滚由它派生的结论（依赖可重放）；
  4. 追溯受影响的输出（哪些回复 / 报告引用了它），必要时更正；
  5. 处置动作审计留痕。
- **后置**：污染不再参与决策；影响面可解释
- **条款**：记忆 8.6、8.3、8.4
- **验收**：S-07

## 3. 逻辑视图

### 3.1 分层结构与依赖规则

```
L1 接入层     儿童会话界面 | 家长视图 | 内容包接收 | 适口性审查
                    │
L2 编排层     会话编排器 | 主动沟通编排器 | 探针调度器 | 任务调度器 | 重算引擎
                    │
L3 领域层     证据域 | 掌握度域 | 记忆域 | 压力域 | 内容域 | 身份与治理域
                    │
L4 网关层     证据网关 | 检索服务 | 推理网关 | 导出导入服务 | 家长直连服务
                    │
L5 基础设施   存储 | 时钟 | 加密与密钥 | 审计 | 嵌入与索引 | 离线队列 | 配置
```

**依赖规则**（三条，违反即架构违规）：

1. 依赖只能自上而下；同层不得横向直连，跨领域协作经接口。
2. **三个单一入口**：写证据只经证据网关；读记忆只经检索服务；外发只经推理网关（+ 内容下行与家长直连两个受控通道）。
3. 领域层的状态**只能由重放引擎**写入；策略类组件（难度、压力、沟通选题）对状态**只读**。

### 3.3 关键机制协作

**M1 作答→证据→投影**（支撑 UC-02/03/08）

```
会话编排器 ──提交(原始交互)──► 证据网关
                                 │ ① 按元数据版本解析关联与难度 → 诊断性
                                 │ ② 跳过分流 → 行为信号
                                 │ ③ 归因判定（上游未解决？过载窗口？）
                                 ▼
                            证据日志（追加，事件时间） ──► 版本标记推进
                                 ▼
                            重放引擎（增量）
                                 │ 水平滞回 + 时效原因码 + 两段证据守卫
                                 ▼
                            投影（外环）───► 全景服务 ──► 四端只读
```

**M2 遗忘传播**（支撑 UC-08/09）

```
确认遗忘事件 ──► 传播策略：requires 闭包 ∩ {部分掌握, 达标}
                    │ 只降时效 → 待重验(原因=上游遗忘)
                    ▼
              探针调度器：与元数据重算浪潮聚合为一次诊断小节
                    │ 小节内先上游后下游
                    ▼
              执行探针 ──► 分级证据回流证据网关
                    │ 上游未重建期间的失败 → 标记"受上游阻塞"，不计 Strike
                    ▼
              上游重建后：下游待重验仍存续，由自身探针解决
```

**M3 对话上下文组装与最小必要外发**（支撑 UC-05/06）

```
儿童发言 ──► 会话编排器 ──► 检索服务
                              │ 过滤：状态 → 受众 → 敏感度（先行）
                              │ 召回 → 精排 → 截断
                              └─► 结果 + 审计记录
                                    ▼
                              推理网关：组装（对话历史 + 截断记忆 + 指令）
                                        ├─ 禁发清单校验（非空即拒，红线）
                                        └─ 调用审计
                                    ▼
                              云端 LLM ──► 适口性审查 ──► 儿童端
```

**M4 难度选择与压力响应**（支撑 UC-03/07）

```
投影(掌握度) ──┐
压力档位 ──────┼──► 难度选择器：在难度属性向量上取点
行为信号 ──────┘        │
                        ▼
               过载检测器 ──有信号──► 响应序列：① 加支撑
                                             ② 降节奏（可即时，无需授权）
                                             ③ 降难度（仅当 ① 无效；儿童端不可见）
                        │
                        └─连续成功达阈值──► 加压授权（一次一档，可回退）
```

**M5 删除级联**（支撑 UC-15）

```
家长验证（C4，每次单独）──► 删除执行器
                              ① 先清内核：证据日志 / 记忆本体+版本链 / 同意记录
                              ② 再废外环：投影 / 全景 / 向量索引 / 摘要
                              ③ 通知家长 App 副本失效（离线则标记待失效）
                              ④ 历史报告去标识或删除（删除优先于不可变）
                              ⑤ 审计留痕
```

**M6 元数据版本切换与重算**（支撑 UC-17）

```
内容包 ──验签──► 内容包管理器（新版本注册，带变更日志）
                     ▼
               重算引擎：闲置/充电窗口全量重放
                     │ 期间旧投影继续服务；版本标记检测不一致
                     ▼
               差异 ──► 探针调度器（聚合为一次诊断小节）
               差异 ──► 家长可解释变更说明
```

### 3.4 模块接口清单（签名级）

| 接口 | 签名 | 不变量 |
| --- | --- | --- |
| 证据网关 | `submit(profile, rawInteraction, metaVersion) → Accepted(id) \| Rejected(reason) \| Deferred` | 幂等；归因先于持久化；跳过不落为失败 |
| 重放引擎 | `replay(profile, evidenceRange, metaVersion, clockAnchor) → ProjectionDelta` | 确定性；同三元组同结果 |
| 投影读取 | `read(profile, scope) → PanoramaSnapshot` | 四端同源；版本标记可检 |
| 检索服务 | `recall(consumer, query, metaVersion) → {items, filtered[], auditId}` | 过滤先行；截断；审计必产出 |
| 推理网关 | `invoke(purpose, messages, recallAuditId) → Response \| Queued` | 禁发清单恒空；逐调用审计 |
| 探针调度器 | `tick(now) → ProbeBatch (≤ budget)` | aging 生效；小节聚合；先上游后下游 |
| 记忆写入器 | `write(candidate, source) → Written \| Merged \| Rejected \| FailedObservable` | 门槛；去重；显式触发失败可见 |
| 删除执行器 | `purge(profile, consentProof) → PurgeReport` | 先内核后外环；级联完整 |
| 导出导入 | `export(profile, consentProof) → SealedFile` / `import(file, consentProof) → ImportReport` | 认证加密；验签失败整体拒绝；幂等 |
| 内容包管理器 | `mount(signedPackage) → MetaVersion \| Rejected` | 快照不可变；验签；推断边隔离 |
| 时钟服务 | `now() / monotonic() / anchor()` | 单调；回拨不倒退 |
| 配置 | `get(key) / set(key)` | 全部阈值可配，有默认值 |
