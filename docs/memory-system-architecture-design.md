### 1.3 设计原则（六条，由约束推导）

1. **三个咽喉点**：一切证据写入经**证据网关**；一切记忆读取经**检索服务**；一切 LLM 调用经**推理网关**。最硬的三条防线（直接证据准入、检索准入过滤、最小必要上下文）收口在三处，禁止任何旁路。
2. **状态即投影**：掌握度等一切派生量是证据日志的确定性投影，物化存储仅为缓存（带版本标记）；任何怀疑即重算。
3. **策略只读**：推荐、压力、沟通选题、探针编排只读投影与记忆，不写状态；其输出回流必须再经证据网关成为证据。
4. **物理档案隔离**：每个儿童档案独立加密数据库文件，隔离不依赖查询层 WHERE 子句（AP-LC-08 纵深防御）。
5. **时间统一注入**：全系统唯一时钟服务，禁止散落的真实时间调用。
6. **一切外发留审计**：四条白名单通道各有专属组件，各自内置审计。

### 2.4 核心用例详述

#### UC-03 作答并获得反馈

- **参与者**：儿童（主）
- **前置**：档案已激活；C1 已同意；有可出题知识点
- **主成功场景**：
  1. 按难度属性向量选题（难度 = 当前掌握度 + 压力档位共同决定）；
  2. 儿童作答；
  3. 判定正误，产出**信息性反馈**（位置与下一步），不含分数、对错计数、比较；
  4. 交互作为原始证据提交证据网关；
  5. 网关按当前元数据版本解析关联与难度 → 判定诊断性 → 标记归因（跳过 → 行为信号；上游阻塞 / 状态受限 → 对应标记）；
  6. 证据持久化（事件时间），触发投影增量更新；
  7. 水平与时效更新，必要时触发加压授权 / 记忆写入 / 探针安排。
- **扩展流**：
  - 3a 答错 → 响应序列第 ① 档（加支撑），不直接降难度；连续失败走有机崩盘两段证据；
  - 3b 跳过 / 未作答 → 不记正确也不记失败，入行为信号，不入正确率分母；
  - 4a 前兆信号窗口内 → 证据标记"受状态受限"，不计 Strike、不参与 μ 更新；
  - 6a 写入失败且显式触发 → 重试至成功或明确告知未记住；
  - 7a 成功达阈值 → 加压授权，难度升一档（一次一档）。
- **后置**：证据入日志；投影一致；反馈已呈现；无评价性内容
- **条款**：压力 3.1 / 4.2 / 4.3 / 5.2 / 6.1 / 6.2 / 7.1、生命周期 5.1 / 5.3 / 6、记忆 5.4
- **验收**：M-24 / M-25 / M-26 / M-28 / M-29 / M-30 / W-06

#### UC-05 与伴学对话

- **参与者**：儿童（主）、云端 LLM（支撑）
- **前置**：会话中；C1 已同意；网络可用（否则 UC-18）
- **主成功场景**：
  1. 儿童发言；
  2. 提取当前学习场景（科目 / 知识点 / 会话目标）为检索上下文；
  3. 检索服务：准入过滤（状态 → 受众 → 敏感度）→ 混合召回 → 精排 → 截断，产出条目与审计记录；
  4. 推理网关：组装最小必要上下文（对话历史 + 截断记忆 + 指令），禁发清单校验（家长标注 / 加密记忆 / 审计日志 / 他档数据恒空）；
  5. 云端 LLM 返回；
  6. 回复过适口性审查（无翻旧账、无贬损、无编造记忆）；
  7. 呈现；"语义提取"任务入智能级队列；
  8. 队列任务联网执行后，结果回证据网关走写入门槛。
- **扩展流**：
  - 3a 检索未命中 → 回复不得出现"你上次…""你已经…"类记忆性表述；
  - 4a 禁发清单非空 → 拒绝发出，记录违规（架构红线）；
  - 6a 审查不通过 → 重写或降级为中性表述；
  - 6b 涉及"上次"表述 → 必须能关联到第 3 步审计记录，否则不得输出。
- **后置**：对话完成；审计留痕（检索命中 + 调用载荷构成）；无禁发内容出设备
- **条款**：记忆 6.5 / 8.5、部署 7.1–7.4、伴学 5.4 / 5.5、AP-LC-13
- **验收**：R-01、C-01、C-05、BD-10、S-04

#### UC-08 掌握度演化与传播

- **参与者**：C 系统自治子系统
- **前置**：新证据已入库
- **主成功场景**：
  1. 重放引擎按 (证据, 时间, 元数据版本) 增量重算受影响知识点；
  2. 更新 μ 与 c（按来源权重、诊断性、归因状态）；
  3. 双阈值滞回更新水平（未知 / 未达标 / 部分掌握 / 达标）；
  4. 诊断性证据更新时效（有效 / 待重验，带原因码）；
  5. 确认遗忘 → 记录遗忘事件，沿已确认 `requires` 闭包向下游传播（仅部分掌握 / 达标下游，只降时效不降水平）；
  6. 传播产生的待重验项交探针调度器（UC-09）。
- **扩展流**：
  - 3a 有机崩盘 → 不直接降级，排确认探针；确认仍支持低水平才降级；
  - 3b 阈值附近震荡 → 滞回带吸收，状态不抖动；
  - 5a 上游恢复 → 不自动清除下游待重验，各自探针解决；
  - 2a 归因为受上游阻塞 / 受状态受限 → 不计 Strike、不触发降级（后者不参与 μ 更新）。
- **后置**：投影与证据一致；版本标记推进；降级 / 遗忘事件可追溯
- **条款**：生命周期 2.2 / 3 / 5.2 / 5.3 / 6 / 7
- **验收**：M-02、M-05、M-06、M-08、M-15、M-17、M-21、M-28、M-29

#### UC-09 探针调度与执行

- **参与者**：C 系统自治子系统
- **前置**：存在待重验项（四原因码：到期 / 重激活 / 上游遗忘 / 首败待确认）、崩盘确认探针需求（不经时效轨，生命周期 6）或评估唤起需求
- **主成功场景**：
  1. 汇总全部候选来源，按优先级排序（当前学习路径到期 > 上游遗忘 > 评估唤起）；
  2. 叠加 aging：连续未服务超阈值的项临时升级，保证最终服务；
  3. 受每日预算约束（本地自然日；跨午夜会话不中断）；
  4. 图传播浪潮与元数据重算浪潮聚合为一次诊断小节；
  5. 小节内先上游后下游；
  6. 探针结果作为分级证据回流（半对半错 → 部分掌握，不硬降）；
  7. 探针按归因规则处理（上游未重建期间的失败 → 受上游阻塞）。
- **扩展流**：
  - 1a 长期饥饿 → aging 升级获得服务；
  - 3a 超预算 → 本轮不执行，留待下周期（记录等待时长供 aging 判定）；
  - 5a 上游未重建 → 下游探针失败标记阻塞，不计 Strike。
- **后置**：探针结果入日志；预算与饥饿指标可观测
- **条款**：生命周期 5.4 / 6 / 7.4 / 7.5 / 9
- **验收**：M-09、M-10、M-20、M-23

#### UC-06 接受主动沟通

- **参与者**：C（发起）、儿童（接受 / 拒绝 / 无视）
- **前置**：C1 已同意；非专注作答 / 深度任务；未触达总量控制
- **主成功场景**：
  1. 从五类锚点选择话题（知识缺口 / 知识连接 / 掌握度变化 / 兴趣延伸 / 初始画像[仅冷启动]）；
  2. 按沟通档位与节奏检查（安静 / 适度 / 话痨）；
  3. 记忆类表述必须由检索记录支撑（同 UC-05 第 3、6 步）；
  4. 发起；记录锚点标签、时机、儿童反馈。
- **扩展流**：
  - 0a 专注作答中 → 不插话（除非求助或明显卡壳）；
  - 3a 儿童发出结束信号 → 当轮收尾，不开新话题；不得以记忆内容挽留；
  - 1a 冷启动 → "初始画像"锚点探测；探测不得产出"未掌握"结论；
  - 0b 未同意 C1 → 非记忆锚点（课程结构、当日内容），不退化为纯被动。
- **后置**：话题与反馈入日志；无挽留、无评价、无编造
- **条款**：伴学 5.1–5.6、部署 4.1、压力 6.1
- **验收**：C-02、C-04、C-06、N-01

#### UC-01 首次启用与同意

- **参与者**：家长（主）
- **前置**：首次开机或新建档案
- **主成功场景**：
  1. 家长身份验证；
  2. 逐项征求 C1–C5（默认安全：C1 关、C5 关）；
  3. 创建档案，生成档案密钥（与密文分离）；
  4. 引导进入初始画像探测（可跳过）；
  5. 初始估计一律低置信度；建档与同意事件入审计。
- **扩展流**：
  - 2a 未同意 C1 → 记忆功能不可用；主动沟通用非记忆锚点，不退化为纯被动；该状态只应存在于首次引导流程中；
  - 2b 同意 C5 → 仅传输不可逆识别数据，可在出网审计验证。
- **后置**：档案可激活；同意可查询可撤回；无任何预写记忆
- **条款**：部署 4.1–4.3、伴学 6.7、记忆 8.2
- **验收**：BD-01、BD-06、BD-08、N-01

#### UC-10 查看学情报告

- **参与者**：家长（主）
- **前置**：家长验证通过；C1 已同意
- **主成功场景**：
  1. 家长端请求全景与报告；
  2. 读取同源全景投影（与推荐 / 复习 / 选题同一来源）；
  3. 呈现可解释报告：知识点状态 + 证据链（哪些证据、何时、推出什么结论）；
  4. 元数据重算差异以"因关联标注修正，重新评估了这批知识点"解释。
- **扩展流**：
  - 3a 负面评价 → 带有效期与重验证机制，不作为永久事实；
  - 3b 请求儿童端同款数值 → 儿童端一律不呈现数值（双通道分层）；
  - 4a 请求记忆原文 → 仅返回 audience 允许家长查看的部分。
- **后置**：报告可追溯；历史报告不改写（删除权例外除外）
- **条款**：伴学 7.5 / 7.6、AP-LC-28、记忆 8.1、生命周期 2.3
- **验收**：P-02、P-03、L-04、M-12

#### UC-15 删除档案

- **参与者**：家长（主）
- **前置**：家长验证通过；每次单独验证
- **主成功场景**：
  1. 二次确认（说明不可恢复）；
  2. 删除执行器**先清内核**（证据日志、记忆本体含版本链、审计可识别部分、同意记录）；
  3. **再废外环**（投影、全景、向量索引、摘要）；
  4. 通知家长 App 副本失效；
  5. 历史报告去标识或删除——**删除优先于不可变**；
  6. 全程审计留痕。
- **扩展流**：
  - 4a App 不在线 → 标记待失效，下次直连强制同步；
  - 5a 报告已导出为文件 → 无法回收，删除前告知家长。
- **后置**：档案不可恢复；无残留派生数据；审计可查
- **条款**：记忆 8.1、部署 4.1 / 8、生命周期 2.3 例外
- **验收**：S-06、BD-01、BD-11

#### UC-17 内容包更新与元数据重算

- **主成功场景**：
  1. 验签；失败拒绝挂载并保留旧版本；

- **扩展流**：
  - 3a 含 split / merged / retired 知识点 → 学情按继任链迁移；退役 code 不复用；
  - 3b 推断来源边 → 不参与传播与门禁，仅推荐邻接。
- **后置**：版本单调递增；旧版本可指定回放；已发报告不改写
- **条款**：知识契约 3.3 / 4.2 / 6 / 7
- **验收**：S-05、M-12、M-19、M-27

#### UC-20 污染处置

- **参与者**：教研 / 运营（发现）、C（执行）

- **验收**：S-07

#### UC-18 离线使用与恢复（简述）

断网期间：数据级操作（作答证据、状态演化、复习调度、本地检索、导出导入、家长直连）正常；智能级（对话生成、语义提取、对话证据评估、对话内容分析）暂停并持久排队。恢复联网后按**事件时间**补处理。离线时前兆检测仅剩行为类信号，且不得放宽加压条件。（部署 2.5、压力 8.1；验收 N-06）

# 第二部分 · 逻辑视图

## 3. 逻辑视图

### 3.1 分层结构与依赖规则

```
L1 接入层     儿童会话界面 | 家长视图 | 内容包接收 | 适口性审查
L2 编排层     会话编排器 | 主动沟通编排器 | 探针调度器 | 任务调度器 | 重算引擎
L3 领域层     证据域 | 掌握度域 | 记忆域 | 压力域 | 内容域 | 身份与治理域
L4 网关层     证据网关 | 检索服务 | 推理网关 | 导出导入服务 | 家长直连服务
L5 基础设施   存储 | 时钟 | 加密与密钥 | 审计 | 嵌入与索引 | 离线队列 | 配置
```

**依赖规则**（违反即架构违规）：

1. 依赖只能自上而下；同层不横向直连，跨领域协作经接口；
2. **三个单一入口**：写证据只经证据网关；读记忆只经检索服务；外发只经推理网关（内容下行与家长直连为受控通道）；
3. 领域状态**只能由重放引擎**写入；策略类组件（难度、压力、选题）对状态**只读**。

### 3.3 关键机制协作

**M1 作答 → 证据 → 投影**（UC-02/03/08）

```
会话编排器 ──提交(原始交互)──► 证据网关
                                │ ① 按元数据版本解析关联与难度 → 诊断性
                                │ ② 跳过分流 → 行为信号
                                │ ③ 归因判定（上游未解决？过载窗口？）
                                ▼
                           证据日志（追加，事件时间）──► 版本标记推进
                                ▼
                           重放引擎（增量）
                                │ 水平滞回 + 时效原因码 + 两段证据守卫
                                ▼
                           投影（外环）──► 全景服务 ──► 四端只读
```

**M2 遗忘传播**（UC-08/09）

```
确认遗忘事件 ──► 传播策略：requires 闭包 ∩ {部分掌握, 达标}
                    │ 只降时效 → 待重验(原因=上游遗忘)
                    ▼
              探针调度器：与元数据重算浪潮聚合为一次诊断小节（先上游后下游）
                    ▼
              执行探针 ──► 分级证据回流证据网关
                    │ 上游未重建期间的失败 → 受上游阻塞，不计 Strike
                    ▼
              上游重建后：下游待重验仍存续，由自身探针解决
```

**M3 对话上下文组装与最小必要外发**（UC-05/06）

```
儿童发言 ──► 会话编排器 ──► 检索服务
                              │ 过滤：状态 → 受众 → 敏感度（先行）
                              │ 召回 → 精排 → 截断 ──► 结果 + 审计记录
                                    ▼
                              推理网关：组装（对话历史 + 截断记忆 + 指令）
                                        ├─ 禁发清单校验（非空即拒，红线）
                                        └─ 调用审计
                                    ▼
                              云端 LLM ──► 适口性审查 ──► 儿童端
```

**M4 难度选择与压力响应**（UC-03/07）

```
投影(掌握度) ──┐
压力档位 ──────┼──► 难度选择器：在难度属性向量上取点
行为信号 ──────┘        │
                        ▼
               过载检测器 ──有信号──► 响应序列：① 加支撑
                                             ② 降节奏（可即时，无需授权）
                                             ③ 降难度（仅当 ① 无效；儿童端不可见）
                        └─连续成功达阈值──► 加压授权（一次一档，可回退）
```

**M5 删除级联**（UC-15）

```
家长验证（C4，每次单独）──► 删除执行器
                              ① 先清内核：证据日志 / 记忆本体+版本链 / 同意记录
                              ② 再废外环：投影 / 全景 / 向量索引 / 摘要
                              ③ 通知家长 App 副本失效（离线则标记待失效）
                              ④ 历史报告去标识或删除（删除优先于不可变）
                              ⑤ 审计留痕
```

**M6 元数据版本切换与重算**（UC-17）

```
内容包 ──验签──► 内容包管理器（新版本注册，带变更日志）
                     ▼
               重算引擎：闲置/充电窗口全量重放（旧投影续服；版本标记检测不一致）
                     ▼
               差异 ──► 探针调度器（聚合为一次诊断小节）
               差异 ──► 家长可解释变更说明
```

### 3.4 模块接口清单（签名级）

| 接口 | 签名 | 不变量 |
| --- | --- | --- |
| 证据网关 | `submit(profile, rawInteraction, metaVersion) → Accepted(id) \| Rejected(reason) \| Deferred` | 幂等；归因先于持久化；跳过不落为失败 |
| 重放引擎 | `replay(profile, evidenceRange, metaVersion, clockAnchor) → ProjectionDelta` | 确定性；同三元组同结果 |
| 投影读取 | `read(profile, scope) → PanoramaSnapshot` | 四端同源；版本标记可检 |
| 检索服务 | `recall(consumer, query, metaVersion) → {items, filtered[], auditId}` | 过滤先行；截断；审计必产出 |
| 推理网关 | `invoke(purpose, messages, recallAuditId) → Response \| Queued` | 禁发清单恒空；逐调用审计 |
| 探针调度器 | `tick(now) → ProbeBatch (≤ budget)` | aging 生效；小节聚合；先上游后下游 |
| 记忆写入器 | `write(candidate, source) → Written \| Merged \| Rejected \| FailedObservable` | 门槛；去重；显式触发失败可见 |
| 删除执行器 | `purge(profile, consentProof) → PurgeReport` | 先内核后外环；级联完整 |
| 导出导入 | `export(profile, consentProof) → SealedFile` / `import(file, consentProof) → ImportReport` | 认证加密；验签失败整体拒绝；幂等 |
| 内容包管理器 | `mount(signedPackage) → MetaVersion \| Rejected` | 快照不可变；验签；推断边隔离 |
| 时钟服务 | `now() / monotonic() / anchor()` | 单调；回拨不倒退 |
| 配置 | `get(key) / set(key)` | 全部阈值可配，有默认值 |

## 4. 运行时契约（逻辑视图的语义基础）

六份契约定义三个咽喉点与治理域"承诺什么"；违反时的对应用例即否证标准。

### K1 · 证据契约

- **前置**：档案上下文 + 原始交互 + 当前元数据版本
- **后置**：证据持久化并纳入重放序列；或明确拒绝 / 降级（失败可见）
- **不变量**：无直接证据不入库，推断不落盘；跳过 → 行为信号，不为失败或正确；归因标记在持久化前写入；`evidence_id` 幂等，事件时间不可变；显式触发失败可观测，自动类留痕；写入不阻塞主流程
- **否证**：W-06、M-30、M-28、X-03

### K2 · 投影契约

- **前置**：证据日志 + 时钟 + 元数据版本
- **后置**：投影 = f(三元组) 的唯一确定结果
- **不变量**：确定性（同输入同输出）；投影可丢弃（删除不损失信息）；版本标记使不一致可检测；调度参数为派生值；降级判定只对部分掌握 / 达标生效
- **否证**：X-01、X-07、M-29、M-12

### K3 · 读取契约

- **前置**：消费方身份（儿童端 / 家长端 / 策略层 / 报告）
- **后置**：结果集 + 审计记录（命中项与被过滤项及原因码）
- **不变量**：准入过滤先行（状态 → 受众 → 敏感度）；受众过滤在检索层强制；截断必须有；延迟预算内返回；四端同源；不得绕过本契约直读记忆库
- **否证**：S-04、R-05、C-05、R-03

### K4 · 外发契约

- **前置**：已组装推理请求 + 目的声明（或内容拉取 / 家长直连请求）
- **后置**：审计记录；或拒绝
- **不变量**：四通道白名单之外零外发；禁发清单恒空；最小必要（对话历史 + 截断记忆 + 指令）；逐调用审计；离线入持久队列且补处理带事件时间
- **否证**：BD-07、BD-10、BD-09、N-06

### K5 · 治理契约

- **前置**：家长验证 + 对应同意项（C1–C5）
- **后置**：操作完成 + 审计；或拒绝
- **不变量**：同意不常驻；撤回 C1 = 停用不删除；导出认证加密零明文，导入验签失败整体拒绝；导入幂等并集 + 全量重放，信任不升级；删除优先于不可变（级联完整）；密钥与密文分离
- **否证**：BD-01 / BD-02 / BD-03 / BD-05、S-06、BD-11、BD-06

### K6 · 内容契约

- **前置**：签名内容包
- **后置**：验签后只读挂载 + 版本注册
- **不变量**：快照不可变、单调递增、强制变更日志；推断边不参与传播与门禁；requires 构 DAG；kp_code 不透明、跨版本不变、退役不复用；无绑定题目不产生学情证据
- **否证**：S-05、M-12、M-19、M-27

## 5. 存储、信任与资源

### 5.1 存储分层（按丢失后果分类）

| 层 | 内容 | 丢失后果 | 可否重建 |
| --- | --- | --- | --- |
| **内核（不可重建）** | 证据日志、审计日志、同意记录、记忆条目本体（含 supersedes 链）、密钥 | 不可恢复：真相丢失 | ✗ |
| **可重建外环** | 掌握度投影、全景、向量索引、摘要、倒排 | 无信息损失 | ✓（重放 / 重算） |
| **可再获取** | 内容包及其衍生索引 | 无信息损失 | ✓（重新下载 + 验签） |

三条规则：**备份只备份内核**；**删除先删内核再废外环**（顺序反了会产生指向已删记忆的索引残留）；**"不确定就重算"只允许发生在外环**——内核永不被重写（唯一例外是删除权终态处置）。

### 5.2 信任域与通行证

| 域 | 内容 | 可见方 |
| --- | --- | --- |
| A 儿童域 | 儿童对话、作答、呈现素材 | 儿童端、策略层（读） |
| B 成人域 | 家长标注、报告、控制项 | 家长端、策略层（读） |
| C 系统域 | 证据元数据、审计、探针编排 | 策略层、治理组件 |

规则：跨域读取需**每次显式声明用途 + 落审计**的通行证（非权限位，防"一次授权终身可读"漂移）；A 不可见 B 的内容，只能感知 B 的策略效果；C 可读 A/B 但受 K4 约束——**读得到 ≠ 发得出**。

### 5.3 存储与部署布局

```
设备本地
├── profiles/<child_id>/          ← 每档案独立（物理隔离）
│   ├── evidence.db      (加密 SQLite, WAL；证据日志+审计)
│   ├── memory.db        (加密 SQLite；记忆库+版本链)
│   ├── projection.db    (物化投影，可随时废弃重建)
│   └── vectors.idx      (派生索引，删除级联对象)
├── content/versions/<meta_ver>/  ← 只读内容包（验签后挂载）
├── keystore/                     ← 档案密钥（与密文分离）
└── consent.db                    ← 同意状态（C1–C5）
```

四条白名单通道 ↔ 组件：内容下行 → 内容包管理器；家长直连 → 家长直连服务；推理调用 → 推理网关；匿名遥测（C5，默认关）→ 独立模块经出网审计。技术选型基线（YAGNI）：SQLite 承载全部结构化存储；向量检索用 SQLite 向量扩展或轻量本地索引；嵌入模型为移动级量化模型（R1 待硬件确认）；进程内任务队列替代消息中间件。

### 5.4 重放架构细节

- **投影版本标记**：`(meta_version, last_evidence_seq, clock_anchor)`；读取方先比对，不一致即触发重算；
- **确定性**：重放只依赖三元组；证据按 (事件时间, evidence_id) 全序化，并发序与真实墙钟在入口处消解（单写者保证）；
- **元数据切换**：全量重算安排在充电 / 闲置窗口；期间旧投影续服；差异聚合为诊断小节；
- **X-01 自比对**：物化投影 vs 重放结果的一致性断言常态化（CI 每日随机剧本）。

### 5.5 资源预算（单档案量级）

| 项 | 估算 | 说明 |
| --- | --- | --- |
| 证据量 | 日十条级 → 10 年 ~40k 条 | 部署规范 1 |
| 证据存储 | ~20 MB（10 年） | 加密 SQLite |
| 记忆条目 | 千级 → 数 MB | 含版本链 |
| 向量索引 | ~8 MB（万级 × 384 维 fp16） | kp 千级 + 记忆千级 |
| 嵌入模型 | 20–80 MB（内存峰值 100–200 MB） | **R1 待硬件确认** |
| 全量重放 | 40k 证据 → 百毫秒级 | 纯 CPU 状态机 |
| 检索延迟 | ≤ 500 ms 预算 | 记忆 6.4 |

结论：单档案全量数据百 MB 量级以内，本地 SQLite 完全承载。

## 6. 执行模型与失效模式

### 6.1 执行模型与并发

- **单写者**：证据日志由单一写者持有，序号单调 → 证据天然全序，K2 确定性的结构性前提；
- **任务优先级**：证据写入 > 投影增量 > 探针执行 > 索引维护 > 全量重算 > 索引重建；低优先级可抢占、可延迟至闲置窗口；
- **重算窗口**：充电 + 闲置；旧投影续服，版本标记检测不一致并回退增量补放；
- **读取并发**：无锁读投影（不可变快照 + 版本标记）；不加写锁阻塞儿童作答；
- **崩溃恢复**：证据日志 WAL + `evidence_id` 幂等 → 撕裂重放一致（X-06）。

### 6.2 失效模式分析

| 失效 | 系统行为 | 用户可见 | 数据后果 |
| --- | --- | --- | --- |
| 云端 LLM 不可达 | 智能级暂停、对话降级；作答证据照常 | 对话不可用，学习不中断 | 无 |
| 嵌入模型加载失败 | 写入降级为原文存储；索引延后重建 | 检索暂弱（关键词兜底） | 无 |
| 投影损坏 / 不一致 | 版本标记检出 → 重算 | 短暂延迟 | 无（外环可重建） |
| 证据写入失败 | 显式触发告知；自动类留痕 | 被告知 | 该条丢失（可补救） |
| 存储 / 电量临界 | 停重算与索引，保证据写入 | 性能降级 | 无 |
| 时钟回拨 | 单调钟屏蔽 | 无感 | 无 |
| 密钥丢失 | 按事先定义策略（默认不可恢复） | 档案不可读，家长被告知 | **不可恢复** |
| 内容包验签失败 | 拒绝挂载，保留旧版本 | 无感 | 无 |
| 家长直连劫持尝试 | 配对验证拒绝 | 无感 | 无 |

## 7. 设计决策与架构禁区

### 7.1 设计决策（D1–D8）

| # | 决策 | 理由 | 被否决的替代 |
| --- | --- | --- | --- |
| D1 | 三咽喉点收口 | 最硬的三条防线集中在三处评审，而非散布全库 | 各组件自行读写（防线被遗忘的风险随消费方数量线性增长） |
| D2 | 事件溯源 + 物化投影 | 可重放是第一不变量；导出 / 导入 / 元数据重算 / 污染回滚复用同一机制 | 直接可变状态存储（状态机 v1 的死因重演） |
| D3 | 策略只读、输出回流走证据网关 | 分层约束；策略直接写状态即"推断落盘"变体 | 策略直写状态（压力档位入状态层） |
| D4 | 每档案独立加密库文件 | 物理隔离是纵深防御 | 单库 + child_id 字段（一条漏写 WHERE 即事故） |
| D5 | 本地嵌入模型 | 否则每次写入记忆都外发原文，白名单形同虚设 | 云端嵌入 API |
| D6 | SQLite 全承载 | 单设备量级足够；运维零成本；导出即文件 | 独立向量数据库 / 服务中间件（违反 YAGNI） |
| D7 | 探针编排独立于推荐策略 | 探针是"要孩子作答"的总阀门（预算 / aging / 聚合），多来源共用一个阀门才能防饿死 | 各来源各自排题（预算失控） |
| D8 | 单一时钟服务 + 注入点 | 回拨攻击与测试时间旅行都要求时钟收口 | 各处调用系统时间 |

### 7.2 架构禁区（八条）

1. 除证据网关外不得有任何写证据路径；除检索服务外不得有任何读记忆路径；除推理网关外不得有任何外发路径；
2. 不得在策略层持久化任何状态（压力档位、推荐参数、画像副本）；
3. 不得跨档案查询（连接粒度 = 单档案）；
4. 不得在儿童域渲染路径引入成人域内容；
5. 不得在设备外持久化任何儿童数据（含"临时"缓存）；
6. 不得散落调用系统时间；
7. 不得把派生量作为权威存储；
8. 不得让推断来源的知识图谱边参与门禁或传播。
