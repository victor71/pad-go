## 1. 目的与范围

本文回答一个问题：**单个知识点上的掌握度记忆，如何随证据与时间演化，且演化过程可信、可解释、可重算。**

本文是学习伴侣规范第 7 章（掌握度建模）的落地结构。掌握度的**数值估计**方法不在本文范围内；本文定义的是估计结果所处的**生命周期骨架**——状态、证据准入、迁移守卫与不变量。

## 2. 核心架构与不变量

### 2.1 三层架构

| 层 | 内容 | 职责 |
| --- | --- | --- |
| 属性层 | 派生标量（μ、c、时钟）+ 事件引用 | 承载一切可连续度量的量 |
| 离散状态层 | 水平 × 时效 × 范围（三个正交维度） | 只编码策略需要分支的最小组合 |
| 策略层 | 探针调度、诊断小节、预算、推题 | 消费状态，不写状态（产品层） |

### 2.2 核心签名（必须）

```
state = f(证据日志, 时间, 元数据版本)
```

- **证据日志**：只含直接证据（见第 5 章）；
- **时间**：当前时刻；
- **元数据版本**：题目-知识点关联与难度估计的版本。关联 / 难度修正 = 在新元数据版本下整体重算；"哪些证据算诊断性"随版本变化，重算差异可解释。

任何离散状态、派生标量（含 `下次重验时间`、重验间隔）**必须**为该函数的输出，**不得**独立存储为可旁路修改的字段。

### 2.3 不变量清单（必须全部成立）

1. **可重放**：状态可由第 2.2 节签名从零重算（AP-LC-01）；
2. **推断不落盘**：证据日志只收直接证据；跨知识点的图谱推断**可以**在估计层读取时进行，**不得**写入任何知识点的证据日志；
3. **报表流水不可变**：重放只改现值；已生成的历史报告（含遗忘事件记录）不被**重算**追溯改写。**唯一例外是删除权**——法务 / 用户删除要求优先于本不可变性（记忆规范 8.1），此时历史报告按删除要求去标识化或删除，该处置不视为"重算改写"；
4. **每次迁移记录触发原因**（哪条证据 / 哪个时钟 / 哪个事件），供 7.5 家长报告追溯；
5. **搁置期间时钟冻结**；
6. **离散层最小性**：见第 10 章"见括号即压扁"检验。

## 3. 离散状态层（必须）

三个正交维度，各自独立演化：

### 3.1 水平轨（由证据驱动）

`未知 → 未达标 ⇄ 部分掌握 ⇄ 达标`

- 由 μ 与**双阈值滞回**决定：升级线高、降级线低，中间为缓冲带，阈值逐 kp 配置；
- **未知** ≠ 未接触：未知 = 无有效证据（含证据被撤回后重算归零）；未接触 = 从未有过证据记录；
- 证据可双向更新水平；"未知"在证据全部失效时**可以**复现。

### 3.2 时效轨（由时钟与事件驱动）

`有效 ⇄ 待重验`

- **有效**：证据新鲜且一致（不暗示做过探针）；
- **待重验**：进入时必须携带原因码，合法值仅四个：

| 原因码 | 语义 | 探针形态 |
| --- | --- | --- |
| 到期 | 复习计划时钟走到 | 单题低成本探针 |
| 重激活 | 搁置恢复 | 探针（水平保留） |
| 上游遗忘 | 前置知识点确认遗忘，传播而至 | 归入诊断小节 |
| 首败待确认 | 重验首败，等待确认探针 | 短间隔确认探针 |

- **置信崩塌不是原因码**：低置信走评估中通道（第 8 章），不经时效轨。时效轨只回答一个问题——"水平估计的证据还新鲜吗，要不要探针"；
- 时效轨的存在权来自三个事件驱动入口（上游遗忘 / 重激活 / 首败）；若仅剩"到期"，它应被降级为派生布尔。

### 3.3 范围标志（由显式事件驱动）

`活跃 ⇄ 搁置`

- **必须**由显式范围事件触发（孩子放弃探索分支、家长暂停主题、课程方下架）；**不得**由不活跃时长自动触发（避免与到期时钟重复）；
- 搁置不重置水平与时效，时钟冻结；重激活 → 强制时效 = 待重验（原因：重激活），水平保留。

## 4. 属性层

每条 `（儿童, kp_code）` 记录携带：

| 属性 | 说明 |
| --- | --- |
| 掌握度 μ | 水平的连续估计；更新接口见 5.4，算法属方案层 |
| 置信度 c | 估计可信程度；c < 阈值 → 评估中（第 8 章） |
| 最近诊断性证据时间 | 时效时钟的锚点；仅诊断性证据更新（5.2） |
| 重验间隔 | **派生值**：达标者由重验成功史递增；部分掌握 / 未达标用固定（可配置）陈旧窗口 |
| 遗忘事件引用 | 指向事件流水，用于报告与重学优先级 |

上表全部字段**必须**为第 2.2 节签名的输出（派生值），**不得**作为可旁路修改的独立状态；其中时间类字段（时效时钟锚点、重验间隔、`valid_until` / `last_validated` 类有效期）**必须**可由证据与时间重算（记忆规范 v1.4 4.2 / 7.3）。

## 5. 证据规则

### 5.1 直接证据准入（必须）

证据**必须**带完整元数据：来源（答题 / 对话展现 / 自发提及 / 探索行为，对应规范 7.3）、权重、时间、**诊断性**、**归因状态**。

### 5.2 诊断性守卫（必须）

只有**诊断性证据**（难度匹配、非重复、对该知识点有区分度；对话证据按来源权重套同一标准）**可以**重置时效时钟；非诊断证据只更新 μ，不动时钟。无此守卫，简单题喂养会使重验永不触发，与 AP-LC-04 的锚定死循环合流。

### 5.3 归因隔离（必须）

上游处于未达标或待重验未解决期间，下游知识点的**失败证据**标记为"受上游阻塞"：保留（是真实行为观察）、**不计入 Strike、不触发降级**；上游重建（重新达标）后自动解除隔离，由新证据自然取代。

归因标记是直接证据的元数据，不构成"推断落盘"。

### 5.4 探针与更新接口（必须）

- **探针产出分级证据，而非判决**：任何重验 / 确认 / 探测的结果都是证据，水平由证据更新；降级目标 = 证据支持的水平（部分掌握或未达标），不硬编码；
- μ 更新接口 = f(证据{权重, 来源, 诊断性, 归因}, 当前 μ, c)；具体估计模型（BKT / IRT / 其他）属方案层。

## 6. 状态迁移与守卫

| 边 / 事件 | 规则 | 级别 |
| --- | --- | --- |
| 时效 → 待重验 | 带原因码（3.2 四值之一） | 必须 |
| 待重验 → 有效 | 仅诊断性证据（5.2） | 必须 |
| 水平升级 | 多源证据 + 间隔确认（跨时间窗）；"未知→达标"同样需要确认周期，摩擦由投影消化（第 8 章），守卫不放松 | 必须 |
| 水平降级 | 双 Strike：首败 → 待重验（原因：首败待确认）+ 策略软反应（优先复习开始）；确认性证据失败才降级并记录遗忘事件。等待期内的良好诊断性证据按 5.2 自然清理首败 | 必须 |
| 有机证据崩盘 | 非重验场景下，多源失败证据使 μ 击穿降级线 → 不直接降级，必须先安排短间隔**确认探针**，确认性证据仍支持低水平才执行降级并记录遗忘事件。降级守卫由此统一为"两段证据"（重验路径：首败 + 确认；有机路径：崩盘 + 确认）。等待确认期间水平保持原级（滞回带吸收），不经时效轨——此时问题是证据异常而非陈旧。受上游阻塞的失败证据（5.3）不得触发本条 | 必须 |
| 确认探针冷却 | 崩盘驱动的确认探针调度必须带冷却窗口：μ 在降级线附近震荡时，冷却窗口内的重复击穿不重复排针，防止探针风暴挤占预算 | 必须 |
| 确认遗忘 | 记录遗忘事件 + 触发图传播（第 7 章） | 必须 |
| 搁置 / 重激活 | 见 3.3 | 必须 |
| 评估中证据唤起 | c < 阈值期间，策略层安排有区分度的内容补充证据；有自己的唤起时钟，不经时效轨 | 应当 |

升级要确认、降级也要确认——**策略可以软，状态变更必须确认**。

## 7. 图传播规则

上游确认遗忘时：

1. **波及面**：仅水平 ∈ {部分掌握, 达标} 的下游（未知 / 未达标的下游没有掌握假设可怀疑）；传递传播**应当**保留；
2. 传播效果 = 下游时效 → 待重验（原因：上游遗忘）；**只降时效，不降水平**（下游自身的直接证据仍新鲜）；
3. **上游恢复不自动清除**下游的待重验——各自待重验由各自证据解决；
4. 传播浪潮与元数据重算浪潮**必须**在产品层聚合为"诊断小节"，不逐题探针；
5. 诊断小节内部排序：**先上游后下游**（先重建地基再检查楼上），与 5.3 归因隔离互为双保险。

## 8. 产品投影

### 8.1 产品语汇 = 状态组合的投影

| 产品语汇 | 定义 |
| --- | --- |
| 未接触 | 无证据记录 |
| 评估中 | c < 阈值（连续判断，不占离散轨） |
| 已掌握 | 达标 × 有效 × 活跃 |
| 已掌握（待巩固） | 达标 × 待重验（到期 / 重激活）× 活跃。括号内是原因码展示，不是状态分裂 |
| 学习中 | 未达标或部分掌握 × 有效 × 活跃 |
| 待重验 | 任意水平 × 待重验（上游遗忘 / 首败待确认）× 活跃 |
| 搁置 | 范围 = 搁置；投影保留水平（搁置且达标 / 搁置其余） |

### 8.2 到全景（规范 7.6）的映射

已掌握（含待巩固）→ 已掌握；学习中、未接触 → 未掌握；评估中、待重验 → 待验证。三个消费端只读投影，不读内部状态。

### 8.3 儿童端语言（必须）

- 遗忘类事件与状态**不得**以失败 / 惩罚语义呈现（AP-LC-27 / 12）；"未知→达标"确认期呈现为"正在了解你"，不是"未掌握"；
- 待重验、评估中是主动沟通的合法锚点（规范 5.1 锚点 3）。

## 9. 策略层约束

| 约束 | 规则 | 级别 |
| --- | --- | --- |
| 探针总预算 | 所有"要孩子作答"的来源（到期 / 上游遗忘 / 重激活 / 首败确认 / 崩盘确认 / 评估唤起）共用每日预算，与规范 8.2 总量控制同源；超限排序：当前学习路径上的到期 > 上游遗忘 > 评估唤起。每日 = 设备本地自然日；跨午夜会话不中断，自次日起按新预算执行 | 必须 |
| 优先级 aging | 静态排序之上叠加老化升级：待重验项连续未被服务超过阈值（可配置，默认 3 个预算周期）→ 优先级临时升一级，保证最终服务；防止上游遗忘 / 评估唤起类长期饿死（其下游后果：归因隔离长期挂起，知识点既不降级也不确认）。aging 只改服务顺序，不改变诊断小节的聚合归属 | 必须 |
| 诊断小节聚合 | 见 7.4 / 7.5 | 必须 |
| 状态机只标记，产品层聚合 | 状态层不感知预算与呈现 | 必须 |

## 10. 设计原则（由推敲提炼，评审时对照）

1. **状态最小主义**：离散层只编码策略需要分支的最小组合；一切可连续度量的量留在属性层；
2. **见括号即压扁**：任何状态值需要括号、后缀、特判才能描述清楚，即又一维度被压扁的信号（原因码的**展示**不算）；
3. **推断不落盘**；
4. **探针产出证据而非判决**；
5. **策略可以软，状态变更必须确认**（升降级对称的确认要求）；
6. **状态机只标记，产品层聚合**。

## 12. 附录：设计否决链（v1 → v3.2）

> 否决理由与正确答案同等重要——每个被否决的版本记录"死因"，防止未来以新面目复发。

### v1 · 七状态扁平状态机（已否决）

**形态**：无记录 / 学习中 / 待验证 / 已掌握 / 待重验 / 已遗忘 / 已归档，扁平迁移。

**死因：维度压扁**——水平（会不会）× 时效（证据新鲜吗）× 范围（还在学吗）三个正交维度压进一条轴，每漏一个组合就少一条边：

1. 学习中无衰减出口（时钟只装在已掌握上）；
2. 待验证是死胡同（超时无出边；已掌握置信崩塌无入边）；
3. 表图矛盾（"已遗忘"定义含"跌破降级线"，图里只有待重验一条入边）；
4. 遗忘与重新学习是事件 / 策略，被画成状态（FORGOTTEN→LEARNING 边界无法定义）；
5. 重验只有过 / 不过两条边（分级证据无处去）；
6. ARCHIVED 混淆范围标志与生命周期，归档不重置时钟、重激活丢弃水平；
7. "无记录"画成状态节点，掩盖"未知 ≠ 未掌握"。

### v2 · 双轨 + 范围标志（已否决）

**形态**：水平轨（未知/未达标/部分/达标）× 时效轨（已验证/待验证）× 范围标志，遗忘改为边事件，增加图传播。

**死因：轨内压扁 + 图盲**——
