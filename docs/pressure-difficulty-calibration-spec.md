## 1. 目的与范围

上游规范已规定压力相关的**禁止性**条款（不得跳崖 AP-LC-22、不得锚定 AP-LC-04、不得评价性呈现 AP-LC-27、不得挽留 AP-LC-18），但未规定压力调节的**目标函数与机制**。本规范填补这一层：以何为目标、如何加压、如何降压、何时响应。

本规范属策略层（生命周期规范 2.1 三层架构），**不改变**状态层的任何状态与迁移。

## 2. 术语定义

| 术语 | 定义 |
| --- | --- |
| 压力 | 概称；本规范**必须**分解为三个独立维度，不作为单一旋钮存在 |
| 难度压力 | 内容与儿童当前知识储备之间的距离 |
| 节奏压力 | 时限、题量、推进密度带来的负荷 |
| 评价压力 | 来自对错判定、分数、比较与评判语气的负荷 |
| 首次尝试正确率 | 排除重试后的正确比例（区别于含重试的整体正确率） |
| 难度属性向量 | 刻画单题难度的多维属性（脚手架量、步骤数、表征抽象度、知识点位置） |
| 加压授权 | 由儿童自身成功证据解锁的难度上升许可 |
| 压力过载前兆 | 表明负荷超限的可观测行为信号 |

## 3. 核心模型

### 3.1 三向分解（必须）

压力**必须**分解为三个可独立调节的维度：**难度压力、节奏压力、评价压力**。三者**不得**合并为单一"压力度"旋钮——合并会导致调节时连带削减难度，最终退化为永远做简单题（AP-PD-01）。

### 3.2 评价压力恒零（必须）

评价压力**不参与调节**，其目标值**恒为零**。任何以"增加挑战感""让分数更有意义"为由引入评价压力的设计**必须**被拒绝——挑战性来自难度压力，不来自评判。

## 4. 难度压力规范

### 4.1 目标成功率分档（必须）

难度校准**必须**以**首次尝试正确率**为指标，**不得**使用含重试的整体正确率（重试会洗白挫败体验，AP-PD-02）。

| 场景 | 目标首次尝试正确率 | 说明 |
| --- | --- | --- |
| 探索期（学新知识） | 60–70% | 偏低是正常的——目标本来就是"够不着" |
| 巩固期（复习已学） | 85–90% | 刻意偏高——目标是提取练习与信心积累 |
| 诊断探针 | 不适用 | 难度**必须**匹配当前估计（生命周期 5.2），看区分度不看成功率 |

上表为**默认基线**，**必须**可配置并按儿童个体校准（**不得**硬编码）。

**跳过 / 未作答（必须）**：**不得**计入首次尝试正确率的分母——它既非正确也非失败（生命周期规范 5.1）；**应当**作为前兆信号单独统计（8.1）。

### 4.2 难度属性向量（必须）

难度**必须**建模为**题目属性向量**，而非知识点档位。向量的可调维度至少包含四项，按调节幅度从小到大：

1. **脚手架量**（有提示 → 半提示 → 无提示）；
2. **步骤数**（一步 → 两步 → 多步复合）；
3. **表征抽象度**（实物 / 图示 → 符号 → 抽象）；
4. **知识点位置**（沿前置图前移到更靠后的知识点）。

难度升降**必须**在该向量上连续调节；**不得**以"换更难/更简单的知识点"作为唯一的难度手段（那会产生二值跳变，AP-PD-06）。

### 4.3 加压授权（必须）

加压**必须**以儿童自身的成功为授权：连续成功达到配置阈值后方可升档。

- **不得**基于系统自身判断主动加压（期待值、进度计划、"该学到这里了"）（AP-PD-04）；
- 加压的证据基础**必须**是**诊断性证据**（生命周期 5.2）——重复题、简单题刷对**不得**触发加压（与 AP-LC-04 一致）；
- 加压幅度**应当**一次一档，**不得**跳档。

### 4.4 加压可回退（必须）

任何加压**必须**可快速回退，回退延迟**应当**在一题之内；加压与回退**必须**对称可用——只升不降的难度机制与只升不降的掌握度同样有害（AP-PD-08）。

## 5. 节奏压力规范

### 5.1 疲劳与时段折算（必须）

节奏压力**必须**计入会话内疲劳累积与时段差异：同一难度在疲劳状态下的实际负荷更高。疲劳时**应当**优先下调节奏压力，而**不得**据此下调难度（AP-PD-07）——同一道题在疲劳时感觉更难，是个体状态问题，不是能力问题。

### 5.2 节奏可即时下调（必须）

出现压力过载信号时，节奏压力是**可以**立即下调的维度（减少题量、放缓推进、插入轻松环节），**无需**证据授权——这与难度压力不同（难度调整**必须**走 4.3 与第 7 章）。

## 6. 评价压力规范（硬线）

### 6.1 恒零清单（必须）

任何面向儿童的输出**不得**包含：

- 对错计数、"你已经错了 N 次"类表述；
- 分数、百分比、掌握度数值、排名；
- 与同伴的比较，以及与过去自己的贬损性比较（"你以前会做的"）；
- 评判性语气与预设失败的话术（"这题很难，做错也正常"）。

与伴学规范 7.5 双通道呈现、AP-LC-27 一致：数值只进家长端。本条同时封堵 AP-LC-12（把记忆变成监控工具）——用记忆向孩子问责是评价压力的极端形态。

### 6.2 不随难度上升而放宽（必须）

难度压力提高时，评价压力**不得**随之提高或"补偿性出现"。逐题对错反馈**应当**以信息性形式给出（指出具体位置、给出下一步），而非判定性形式。

## 7. 响应序列规范

### 7.1 三档序列（必须）

压力响应的**必须**顺序：

1. **加支撑**（提示、拆解步骤、更换表征）；
2. **降节奏**（减题量、放缓推进）；
3. **降难度**（在 4.2 向量的脚手架 / 步骤 / 表征维度上回退）。

**不得**跳过第 ① 档直接降难度（AP-PD-03）。只有"连续挫折且 ① 无效"时才进入第 ③ 档。理由：降难度传递"你不行"，加支撑传递"我帮你搭个梯子"——后者不损伤胜任感（AP-LC-05）。

### 7.2 降难度不可见（必须）

降难度与加压回退在儿童端**不得**呈现为降级、退步、被判定"跟不上"；呈现**应当**为视角切换（如"我们换个角度看看"）（AP-PD-05）。回退**应当**无声、即时，不留评价痕迹。

### 7.3 支撑留痕（应当）

支撑手段的使用与效果**应当**留痕，用于校准"对哪个儿童、哪种缺口，哪种支撑最有效"。

## 8. 压力过载前兆

### 8.1 信号清单（必须）

系统**必须**可观测压力过载前兆信号，至少包含：

- 响应时间异常缩短（乱猜、秒选）或异常延长（卡住、走神）；
- 连续跳过题目；
- 同一题多次重试；
- 答案模式化（反复选同一选项、随机点击）；
- 会话中途退出；
- 对话回复显著变短或出现回避性回复。

**离线降级（必须）**：离线期间（《部署与数据边界规范》2.5，智能级暂停）依赖对话内容分析的信号不可用，**应当**以行为类信号（响应时间 / 跳过 / 模式化作答 / 中途退出）维持检测；检测能力降级的事实**不得**导致加压条件放宽（保守优先）。

### 8.2 触发规则（必须）

前兆信号**必须**触发第 7 章序列的第 ① 档（加支撑）与 5.2 的节奏下调，且**必须**先于"降难度"生效。

### 8.3 情景归属（必须）

前兆信号属**情景层**，只影响当次会话或当日策略；**不得**上升为长期特质（"容易放弃""注意力差"）——与 AP-LC-06 一致（AP-PD-10）。

## 9. 自主性与压力度

### 9.1 儿童可调（必须）

儿童**必须**能自主调节：难度档位、节奏（题量 / 推进速度）、随时暂停或结束。可选项范围**可以**受限，但**不得**为零（AP-PD-09）。

### 9.2 家长上限（应当）

家长**可以**设置压力上限（与伴学 5.2 沟通分档、8.2 反成瘾一致）；上限**不得**用于强制加压，只**可以**限制加压空间。

### 9.3 控制感是对冲项（必须）

压力调节**必须**向儿童保留控制感——能选、能停、能调。控制感是反感的主要对冲项，**不得**以"最优学习路径"为由剥夺。

## 10. 与状态机 / 生命周期的接口

### 10.1 分层归属（必须）

压力档位是**策略参数**，**不得**进入状态层（生命周期 2.1）——它不改变任何掌握度状态或迁移。

### 10.2 证据基础（必须）

难度校准的输入**必须**是诊断性证据（生命周期 5.2）；非诊断性证据**不得**触发加压（同 4.3）。

**无绑定题目（必须）**：知识契约 5.2 规定无绑定题目不产生学情证据，因此其作答结果**不得**用于难度校准与加压——诊断性判定依赖关联置信度（知识契约 4.4）。

### 10.3 连续失败的处理（必须）

连续失败**必须**走生命周期规范 6 的**有机证据崩盘**路径（崩盘 + 确认探针两段证据），**不得**在一次失败后直接降低掌握度或难度。

### 10.4 参数可配置（必须）

目标区间、加压阈值、疲劳折算参数、前兆信号阈值**必须**可配置且有默认值，**不得**硬编码（呼应用例集"禁止参数固化"编写规范）。

## 11. 反模式

| ID | 反模式 | 严重程度 | 违反 |
| --- | --- | --- | --- |

| AP-PD-02 | 用含重试的整体正确率校准难度 | 严重 | 4.1 |
| AP-PD-03 | 挫折时直接降难度，跳过加支撑 | **高危** | 7.1 |
| AP-PD-04 | 无成功授权的系统自行加压 | 严重 | 4.3 |
| AP-PD-05 | 降难度 / 回退在儿童端可见，传递"你被降级" | **高危** | 7.2 |
| AP-PD-06 | 难度二值跳变（只靠换知识点调难度） | 严重 | 4.2 |

## 13. 与既有文档的接口

- **伴学规范**：本规范是 6.2（难度只看知识储备）、6.3（邻近发展区）的**目标函数与机制**落地；与 7.5（双通道呈现）、8.2（反成瘾）互为约束；
- **生命周期规范**：本规范属策略层（2.1），消费其诊断性判定（5.2）、迁移守卫（6）与探针预算（9）；连续失败处理遵循其有机证据崩盘路径；
- **用例集**：本规范多数条款属纯策略 / 交互层，其验证由专门的子系统用例集承担；与记忆系统的**交点**已入现有用例集（M-24 非诊断证据不加压、M-25 挫折响应序、M-26 降难度不可见）；
- **反模式编号**：AP-PD-01 ~ 10，与 AP-LC / AP-KP / AP-DB 三套编号并列。
