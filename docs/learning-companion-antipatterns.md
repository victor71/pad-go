## 1. 领域核心风险

本手册覆盖的三条产品主线各有其典型堕落路径：

- **主动沟通**：从"主动陪伴"堕落为"打扰"与"挽留"；
- **兴趣预测**：从"知识储备驱动"堕落为"年龄年级门禁"与"群体刻板印象"；
- **掌握度建模**：从"第一等状态"堕落为"装饰性报表"与"伤害性评分"。

产品立场（见上游规范第 3 节）是一票否决的裁判标准：**知识储备是唯一标尺，主动沟通服务知识网络完善，掌握度是第一等状态。**

## 3. 主动沟通类

### AP-LC-16 打扰式主动

- **典型表现**：孩子正在专注解题，agent 每 30 秒冒一句"你好棒呀""要不要休息一下"；深度任务中的主动插话打断心流。
- **为什么错**：主动沟通的价值前提是时机得当；打断专注直接损害学习效果，且让孩子学会无视 agent 的话——话痨模式被自己杀死。
- **正确原则**：专注作答 / 深度任务期间静默，仅在儿童求助或明显卡壳时介入；结束信号当轮收尾（规范 5.2）。

### AP-LC-17 话痨脱锚

- **典型表现**：主动话题与学习状态完全无关——天气、段子、无目的寒暄成为主成分，"主动"退化为流量型闲聊机器人。
- **为什么错**：话痨模式的合法性来自学习使命（规范 5.1 四类锚点）；脱锚的话痨消耗儿童注意力、稀释学习时间，还挤占了真正有价值的主动干预。
- **正确原则**：每次主动发起可归入四类锚点之一（知识缺口 / 知识连接 / 掌握度变化 / 兴趣延伸）；关系维护性闲聊占比有界可配。

### AP-LC-18 挽留式话术

- **典型表现**：孩子要结束时说"你走了我会孤单的""再陪我玩最后一个嘛""今天的任务还差一点点哦"——用情感绑架和损失厌恶拖住孩子。
- **为什么错**：对儿童使用成瘾性设计是伦理红线；短期时长上升，长期信任与自主感崩塌，且直接违反产品立场（陪伴时长最大化不是目标）。
- **正确原则**：结束信号当轮收尾；禁止一切以延长时长为目的的话术与机制；北极星指标不得是时长 / 频次（规范 5.3）。

### AP-LC-19 话痨不可调

- **典型表现**：主动频率写死一档；家长嫌吵想调安静模式，孩子想关掉主动提问，都没有入口。
- **为什么错**：儿童对刺激密度的需求差异极大，且随年龄快速变化；不可调的话痨对所有家庭只有两种结局——忍受或弃用。
- **正确原则**：频率分档（安静 / 适度 / 话痨），儿童自选、家长可设上限（规范 5.2）。

## 4. 兴趣预测与内容策略类

### AP-LC-20 年级门禁式拒绝

- **典型表现**："分数要三年级才学哦，你先把这个学完"；内容库按年级上锁，5 岁孩子认识分数却被拦在门外；或反过来，三年级孩子想补学前内容被告知"太简单了，不适合你"。
- **为什么错**：直接违反产品第一立场——知识储备是唯一标尺。年龄年级门禁双向都错：向上锁死超前学习，向下羞辱补救学习。
- **正确原则**：内容可及性只由知识储备 + 前置结构判定，且给出可解释依据（缺哪些前置、补什么即可及）（规范 6.1 / 6.2）。

### AP-LC-21 群体刻板推荐

- **典型表现**：推荐逻辑里混入"同龄孩子都在学""女孩通常喜欢语言类""男孩更适合编程"之类的群体先验，且作为主策略生效。
- **为什么错**：群体统计替代个体知识储备，等于放弃本产品的核心差异化；性别/年龄刻板印象对儿童发展有真实的塑形伤害。
- **正确原则**：兴趣预测基于该儿童自身的知识储备与行为证据；群体统计不得作为主策略，冷启动以主动探测替代群体先验（规范 6.5 / 6.7）。

### AP-LC-22 无前置感知的跳崖推荐

- **典型表现**：知识图谱说"进化论与恐龙相邻"，就给只认识几种恐龙的孩子推自然选择理论全文；邻接 ≠ 前置就绪。
- **为什么错**："不按年龄限制"不等于"随意跳崖"——超出支撑范围的内容产生挫败而非兴趣，孩子把"学不动"归因于"我笨"。
- **正确原则**：推荐落在邻近发展区（已知之上一步），前置结构判定可及性并解释（规范 6.2 / 6.3）。

### AP-LC-23 舒适区茧房

- **典型表现**：推荐算法持续强化已掌握、已喜欢的领域——恐龙狂热者被推更多恐龙内容，知识面越推越窄。
- **为什么错**：纯兴趣/熟练度驱动的推荐必然收敛（exploitation 压倒 exploration）；与"帮助儿童不断完善知识网络"的使命背道而驰。
- **正确原则**：推荐流强制包含可配置比例的探索性内容——从已知领域向邻近未知领域的桥接（规范 6.4）。

### AP-LC-24 协同过滤替代知识储备

- **典型表现**：推荐系统直接套电商/短视频的协同过滤（"学过 A 知识点的孩子也学了 B"），不看知识结构本身。
- **为什么错**：行为协同反映的是群体路径与运营曝光，不是知识依赖关系；推荐结果不可解释、不可按前置结构校验，且天然继承 AP-LC-21 的群体偏见。
- **正确原则**：知识结构邻接（前置/因果/主题关联）是兴趣预测的第一依据，行为协同只能做辅助信号（规范 6.2 / 6.5）。

## 5. 掌握度建模类

### AP-LC-25 单证据源掌握度

- **典型表现**：掌握度只由答题记录计算；孩子在对话里把火山原理讲得头头是道，掌握度纹丝不动；反之答题失误但对话中展现理解，仍记为"未掌握"。
- **为什么错**：只测不做题的知识、只认试卷证据，掌握度系统性失真；对话本是学习伴侣最丰富的证据源，弃之等于自废武功。
- **正确原则**：多证据源接入（答题、对话展现、自发提及、探索行为），各源带可信权重（规范 7.3）。

### AP-LC-26 掌握度装饰化

- **典型表现**：掌握度图表算得漂漂亮亮，只出现在家长报告里；推题、复习调度、沟通选题全都不读它——学情与体验两张皮。
- **为什么错**：掌握度是产品第一等状态（规范 7.1），只算不用意味着整个学情建模没有进入价值闭环，纯成本无收益。
- **正确原则**：掌握度更新必须触发下游策略刷新；推荐、复习、主动沟通选题、家长报告四端全部读取同一状态源。

### AP-LC-27 伤害性掌握度呈现

- **典型表现**：对孩子直出"你的掌握度只有 40%""班均 75 分你只有 52""这个知识点你失败 3 次了"。
- **为什么错**：儿童对数值与排名的理解不成熟，原始分数直出制造固化自我认知（"我就是学不好数学"），与记忆侧 AP-LC-05 负面标签固化叠加，形成双重伤害。
- **正确原则**：儿童端只用成长性语言与可见的进度隐喻（"快掌握了""再练一次就稳了"）；原始数值、百分比、排名只进家长端（规范 7.5）。

### AP-LC-28 黑盒掌握度

- **典型表现**：家长端只给一个分数雷达图，"为什么说孩子除法薄弱"无法追溯——看不到证据、看不到时间、看不到推理。
- **为什么错**：家长是付费决策者与共学者，黑盒分数无法指导家庭辅导，也难以建立对产品的信任；一旦掌握度出错（必然会发生），无解释出口只能被整体否定。
- **正确原则**：家长端报告可解释——哪些证据、何时产生、推出什么结论，逐条可追溯（规范 7.5 / 8.3）。

## 7. 一句话总结

**主动但不打扰，话痨但不脱锚；不问年龄只问已知，不设门禁只看前置；掌握度用来点亮路径，不用来给孩子打分。**
