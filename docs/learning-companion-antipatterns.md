## 1. 领域核心风险

**记忆域**的最大风险不是技术，而是**用成人静态画像的思路去记一个快速成长的孩子**：

- 孩子的知识、能力、兴趣、情绪都在快速变化，而记忆天然倾向固化；
- 孩子对陪伴角色的信任是绝对的，一句错误的记忆陈述（"你上次做对了"）伤害远大于成人产品；
- 儿童数据是合规红线，且学习机常见多孩共用，隔离失误即事故。

因此：**遗忘、有效期、重验证在教育场景不是 nice-to-have，是产品正确性的一部分。**

**交互·推荐·掌握度域**的三条产品主线各有其典型堕落路径：

- **主动沟通**：从"主动陪伴"堕落为"打扰"与"挽留"；
- **兴趣预测**：从"知识储备驱动"堕落为"年龄年级门禁"与"群体刻板印象"；
- **掌握度建模**：从"第一等状态"堕落为"装饰性报表"与"伤害性评分"。

产品立场（见规范第 3 节）是一票否决的裁判标准：**知识储备是唯一标尺，主动沟通服务知识网络完善，掌握度是第一等状态。**

- **中**：质量与成本损耗，随版本迭代修复。

## 3. 记忆域详述（AP-LC-01 ~ 15）

### 3.1 学情建模类

#### AP-LC-01 答题日志当学情记忆

- **典型表现**：只存答题流水（"6月3日答错第1024题"），检索时把原始日志直接当学情用；或反过来只存掌握度结论，丢弃流水导致无法重算。
- **为什么错**："某次答错某题"是情景记忆，"除法掌握度 60%"是语义记忆，两者混用导致：结论不可追溯、不可重算、不可随策略升级而修正。
- **正确设计**：原始记录全量保留（情景层）；掌握度是从记录**派生**的、带时间戳与置信度的语义结论；掌握度可随时从原始记录重算。派生关系单向：结论可重建，原始记录不可被结论覆盖。
- **关联条款**：主规范 4.1（分层）、4.2（schema）。

#### AP-LC-02 掌握度只升不降，无遗忘曲线

- **典型表现**：9月标记"两位数乘法已掌握"，次年6月仍按已掌握推题。
- **为什么错**：知识会遗忘，不衰减的掌握度会系统性高估孩子水平，推题过难、挫败感累积。
- **正确设计**：掌握度随时间衰减（可参照艾宾浩斯遗忘曲线或指数衰减模型），并由复习/重测刷新；长期未被验证的掌握度自动降级为"待重验"。此条在教育场景由主规范 7.3 的"应当"**升级为必须**（规范 7.2 已明文）。
- **关联条款**：主规范 7.3（时效性）、7.4（遗忘）。

#### AP-LC-03 关联噪声直接传导进学情

- **典型表现**：复合题（一道题同时考"分数减法"和"通分"）只绑一个知识点，答错即记"分数减法薄弱"；题目-知识点关联本身带不确定性，掌握度更新却按确定性处理。
- **为什么错**：上游关联噪声（错标、单绑定假设、复合题误归因）会以 100% 置信度写入学情，错误被放大成"孩子哪里弱"的错误结论，进而驱动错误的推题策略。
- **正确设计**：掌握度更新使用关联的置信度加权；复合题多知识点绑定时做归因分解（或至少分摊降权）；关联数据修正后，学情结论可重算（依赖 AP-LC-01 的原始记录保留）。
- **关联条款**：主规范 4.2（置信度字段）。

#### AP-LC-04 能力/难度锚定

- **典型表现**：孩子 5 岁时"识字弱"的画像，7 岁仍在压低推题难度；系统永远推简单题，孩子永远得不到挑战。
- **为什么错**：初始低置信度先验被当成高置信度长期事实，形成难度-表现的死循环（推题简单→表现平淡→画像不更新）。
- **正确设计**：冷启动画像一律标记低置信度；新证据（尤其与旧画像矛盾的证据）应显著快速地更新画像；定期主动探测（偶尔推送略高于当前估计的题目）打破锚定。
- **关联条款**：主规范 7.2（裁决优先级：时间更近优先）、7.3。

### 3.2 儿童发展特性类

#### AP-LC-05 负面标签固化成永久事实

- **典型表现**："这个孩子数学不好"写成无有效期的语义记忆；agent 据此推简单题、语气居高临下，孩子更没兴趣——自证预言。
- **为什么错**：评价类记忆描述的是**某个时间点**的状态，不是孩子的属性。儿童发展速度快，固化负面评价直接影响产品行为，构成对儿童的心理伤害。
- **正确设计**：任何评价类记忆必须带 `valid_until` 与重验证机制（主规范 4.2）；负面评价的有效期应显著短于正面评价；禁止将负面标签作为 prompt 的默认检索结果；agent 话术层面禁止翻旧账式引用。
- **关联条款**：主规范 7.3、8.2（数据最小化——负面对孩子无益的评价索性别记）。

#### AP-LC-06 情绪状态永久化

- **典型表现**：某天孩子答题时多次沮丧，被固化成"容易沮丧，需降低难度"的长期画像。
- **为什么错**：情绪是高波动情景信号，一次状态被上升为稳定特质后，会错误地长期压制难度和内容选择。
- **正确设计**：情绪信号只入情景层，仅影响当日策略；上升为语义记忆需要跨时间的重复模式 + 明确的产品收益论证，且带短有效期。
- **关联条款**：主规范 4.1（分层写入门槛）、7.4。

#### AP-LC-07 兴趣记忆不过期

- **典型表现**：4 岁记录的"喜欢恐龙"，9 岁还在生成恐龙主题题目。
- **为什么错**：儿童兴趣半衰期短，成人系统的兴趣 TTL 策略直接套用会显得"这个朋友很不懂我"。
- **正确设计**：兴趣记忆 TTL 短（周/月级），靠近期行为刷新；长期未强化的兴趣自动归档而非继续参与检索。
- **关联条款**：主规范 7.4。

### 3.3 安全与合规类

#### AP-LC-08 多孩共用设备画像串味

- **典型表现**：学习机由 siblings 共用且无儿童身份区分，哥哥的错题记录污染妹妹的学情；agent 对妹妹说"你上次学过这个"。
- **为什么错**：记忆按设备而非按孩子隔离，画像互相污染且不可恢复；这是儿童硬件产品的经典事故，直接摧毁两个孩子的学情准确性。
- **正确设计**：记忆库以**儿童档案**为主键隔离，设备只是载体；支持多档切换且有防误切确认；会话开启时明确当前儿童身份。
- **关联条款**：主规范 8.1。

#### AP-LC-09 孩子口述直接当可信事实

- **典型表现**：孩子说"我叫奥特曼、我今年 100 岁"，系统永久记住并据此推题；孩子随口说的家庭信息被固化。
- **为什么错**：儿童陈述的可信结构完全不同——游戏性表达、想象、模仿交织；直接固化为 `user_direct` 级事实会产生荒谬甚至不安全的行为依据。
- **正确设计**：儿童口述默认低可信级别（主规范 4.2 的 `source_trust` 分级可按儿童产品扩展：`user_direct` 细分为已确认 / 未确认），关键事实（姓名、年龄、年级）需通过家长端确认或行为交叉验证后才可提升可信级别。
- **关联条款**：主规范 8.3。

#### AP-LC-10 家长端标注泄漏到孩子端

- **典型表现**：家长在 App 里备注"孩子注意力缺陷"，该记忆被检索进孩子对话的 prompt，agent 说出伤害性表述。
- **为什么错**：成人侧输入的敏感标注与孩子侧的对话记忆未隔离，检索层无端可见性控制，造成心理伤害与信任崩塌。
- **正确设计**：受众域在写入时确定（主规范 4.2 `audience`，家长 / 教师侧标记为 `parent`）；孩子端检索路径不可见成人标注——隔离在**检索层**强制（主规范 6.5 / 8.5），不依赖话术层过滤；成人标注只能通过显式设计的策略层（如难度调整）间接生效，绝不直接进入孩子端 prompt。
- **关联条款**：主规范 8.5（受众隔离）、6.5（检索准入过滤）、8.4（审计）。

#### AP-LC-11 儿童数据最小化与删除权缺失

- **典型表现**：记忆中大量沉淀孩子的情绪细节、家庭对话、错误明细；家长没有查看/编辑/删除入口，或删除后向量索引、摘要等派生数据残留。
- **为什么错**：儿童个人信息受专门法规强约束（未成年人保护相关法规、COPPA/GDPR-K 类要求），超范围收集与不可删除均为合规红线。
- **正确设计**：收集最小化（服务学习目标所必需）；家长端提供完整的记忆查看/编辑/删除入口；删除执行硬删除或不可恢复匿名化，并级联清理所有派生数据（向量、摘要、学情结论中的敏感字段）。
- **关联条款**：主规范 8.1、8.2。

### 3.4 交互体验类

#### AP-LC-12 记忆变成监控工具

- **典型表现**：agent 说"你这周三次没完成练习""你上次也不会这种题"——用记忆对孩子做审判和对比。
- **为什么错**：同样的记忆，用于自适应是价值，用于问责是伤害。孩子感知到"被盯着"后会回避与 agent 交流，长期留存崩塌。
- **正确设计**：记忆进入孩子端 prompt 前经过**适口性审查**：不翻旧账、不做贬损性对比、不引用负性情景细节；检索产出的使用方式限定为鼓励、脚手架和内容适配。审查规则需进入评测集（对应主规范 10.2 的下游任务评估）。
- **关联条款**：主规范 8.2、10.2。

#### AP-LC-13 Agent 编造记忆

- **典型表现**："你上次做对过这道题哦"——检索记录里根本没有这回事。
- **为什么错**：孩子对陪伴角色的信任是绝对的，虚构记忆一旦被发现（孩子记得自己没做过），信任不可逆地受损；且错误记忆陈述可能扭曲孩子的自我认知。
- **正确设计**：agent 任何涉及"上次/之前/你已经"的表述必须由真实检索到的记忆记录支撑；无法检索到依据时使用中性话术；记忆引用路径全程可审计（当时检索了什么、用了什么）。
- **关联条款**：主规范 8.4（审计日志）。

### 3.5 结构与工程类

#### AP-LC-14 教材版本变更后知识点引用失效

- **典型表现**：学情记忆直接挂在章节路径或题号上（"三年级上册第三单元 掌握度 80%"），孩子升学或教材改版后，整份画像作废或错乱。
- **为什么错**：章节路径和题号是不稳定标识；跨学段系统中教材版本、年级、学期都会变化，引用链一断，长期积累的学情资产全部悬空。
- **正确设计**：学情记忆挂在**稳定的知识点编码**上（全局统一、跨教材版本不变的 kp_code）；教材改版时通过知识点映射表迁移学情，而非清零重建；题号仅作为证据引用，不作为挂载点。
- **关联条款**：主规范 4.2。

#### AP-LC-15 全量画像塞进每次 prompt

- **典型表现**：把整份学情档案（所有科目、所有知识点、全部兴趣标签）无差别塞进上下文。
- **为什么错**：token 成本高；过时信息稀释注意力；模型过度迁就旧画像，与 AP-LC-04 叠加后锚定效应更严重。
- **正确设计**：按当前学习场景（当前科目、当前知识点、当日目标）精准检索 3–5 条高相关记忆；画像只保留摘要级锚点，细节按需展开。
- **关联条款**：主规范 6.2（精度优先与截断）。

## 4. 交互·推荐·掌握度域详述（AP-LC-16 ~ 28）

### 4.1 主动沟通类

#### AP-LC-16 打扰式主动

- **典型表现**：孩子正在专注解题，agent 每 30 秒冒一句"你好棒呀""要不要休息一下"；深度任务中的主动插话打断心流。
- **为什么错**：主动沟通的价值前提是时机得当；打断专注直接损害学习效果，且让孩子学会无视 agent 的话——话痨模式被自己杀死。
- **正确原则**：专注作答 / 深度任务期间静默，仅在儿童求助或明显卡壳时介入；结束信号当轮收尾（规范 5.2）。

#### AP-LC-17 话痨脱锚

- **典型表现**：主动话题与学习状态完全无关——天气、段子、无目的寒暄成为主成分，"主动"退化为流量型闲聊机器人。
- **为什么错**：话痨模式的合法性来自学习使命（规范 5.1 五类锚点）；脱锚的话痨消耗儿童注意力、稀释学习时间，还挤占了真正有价值的主动干预。
- **正确原则**：每次主动发起可归入五类锚点之一（知识缺口 / 知识连接 / 掌握度变化 / 兴趣延伸 / 初始画像[仅冷启动]）；关系维护性闲聊占比有界可配。

#### AP-LC-18 挽留式话术

- **典型表现**：孩子要结束时说"你走了我会孤单的""再陪我玩最后一个嘛""今天的任务还差一点点哦"——用情感绑架和损失厌恶拖住孩子。
- **为什么错**：对儿童使用成瘾性设计是伦理红线；短期时长上升，长期信任与自主感崩塌，且直接违反产品立场（陪伴时长最大化不是目标）。
- **正确原则**：结束信号当轮收尾；禁止一切以延长时长为目的的话术与机制；北极星指标不得是时长 / 频次（规范 5.3）。

#### AP-LC-19 话痨不可调

- **典型表现**：主动频率写死一档；家长嫌吵想调安静模式，孩子想关掉主动提问，都没有入口。
- **为什么错**：儿童对刺激密度的需求差异极大，且随年龄快速变化；不可调的话痨对所有家庭只有两种结局——忍受或弃用。
- **正确原则**：频率分档（安静 / 适度 / 话痨），儿童自选、家长可设上限（规范 5.2）。

### 4.2 兴趣预测与内容策略类

#### AP-LC-20 年级门禁式拒绝

- **典型表现**："分数要三年级才学哦，你先把这个学完"；内容库按年级上锁，5 岁孩子认识分数却被拦在门外；或反过来，三年级孩子想补学前内容被告知"太简单了，不适合你"。
- **为什么错**：直接违反产品第一立场——知识储备是唯一标尺。年龄年级门禁双向都错：向上锁死超前学习，向下羞辱补救学习。
- **正确原则**：内容可及性只由知识储备 + 前置结构判定，且给出可解释依据（缺哪些前置、补什么即可及）（规范 6.1 / 6.2）。

#### AP-LC-21 群体刻板推荐

- **典型表现**：推荐逻辑里混入"同龄孩子都在学""女孩通常喜欢语言类""男孩更适合编程"之类的群体先验，且作为主策略生效。
- **为什么错**：群体统计替代个体知识储备，等于放弃本产品的核心差异化；性别/年龄刻板印象对儿童发展有真实的塑形伤害。
- **正确原则**：兴趣预测基于该儿童自身的知识储备与行为证据；群体统计不得作为主策略，冷启动以主动探测替代群体先验（规范 6.5 / 6.7）。

#### AP-LC-22 无前置感知的跳崖推荐

- **典型表现**：知识图谱说"进化论与恐龙相邻"，就给只认识几种恐龙的孩子推自然选择理论全文；邻接 ≠ 前置就绪。
- **为什么错**："不按年龄限制"不等于"随意跳崖"——超出支撑范围的内容产生挫败而非兴趣，孩子把"学不动"归因于"我笨"。
- **正确原则**：推荐落在邻近发展区（已知之上一步），前置结构判定可及性并解释（规范 6.2 / 6.3）。

#### AP-LC-23 舒适区茧房

- **典型表现**：推荐算法持续强化已掌握、已喜欢的领域——恐龙狂热者被推更多恐龙内容，知识面越推越窄。
- **为什么错**：纯兴趣/熟练度驱动的推荐必然收敛（exploitation 压倒 exploration）；与"帮助儿童不断完善知识网络"的使命背道而驰。
- **正确原则**：推荐流与主动沟通选题均强制包含可配置比例的探索性内容——从已知领域向邻近未知领域的桥接（规范 6.4，两通道分别配置）。

#### AP-LC-24 协同过滤替代知识储备

- **典型表现**：推荐系统直接套电商/短视频的协同过滤（"学过 A 知识点的孩子也学了 B"），不看知识结构本身。
- **为什么错**：行为协同反映的是群体路径与运营曝光，不是知识依赖关系；推荐结果不可解释、不可按前置结构校验，且天然继承 AP-LC-21 的群体偏见。
- **正确原则**：知识结构邻接（前置/因果/主题关联）是兴趣预测的第一依据，行为协同只能做辅助信号（规范 6.2 / 6.5）。

### 4.3 掌握度建模类

#### AP-LC-25 单证据源掌握度

- **典型表现**：掌握度只由答题记录计算；孩子在对话里把火山原理讲得头头是道，掌握度纹丝不动；反之答题失误但对话中展现理解，仍记为"未掌握"。
- **为什么错**：只测不做题的知识、只认试卷证据，掌握度系统性失真；对话本是学习伴侣最丰富的证据源，弃之等于自废武功。
- **正确原则**：多证据源接入（答题、对话展现、自发提及、探索行为），各源带可信权重（规范 7.3）。

#### AP-LC-26 掌握度装饰化

- **典型表现**：掌握度图表算得漂漂亮亮，只出现在家长报告里；推题、复习调度、沟通选题全都不读它——学情与体验两张皮。
- **为什么错**：掌握度是产品第一等状态（规范 7.1），只算不用意味着整个学情建模没有进入价值闭环，纯成本无收益。
- **正确原则**：掌握度更新必须触发下游策略刷新；推荐、复习、主动沟通选题、家长报告四端全部读取同一状态源。

#### AP-LC-27 伤害性掌握度呈现

- **典型表现**：对孩子直出"你的掌握度只有 40%""班均 75 分你只有 52""这个知识点你失败 3 次了"。
- **为什么错**：儿童对数值与排名的理解不成熟，原始分数直出制造固化自我认知（"我就是学不好数学"），与记忆侧 AP-LC-05 负面标签固化叠加，形成双重伤害。
- **正确原则**：儿童端只用成长性语言与可见的进度隐喻（"快掌握了""再练一次就稳了"）；原始数值、百分比、排名只进家长端（规范 7.5）。

#### AP-LC-28 黑盒掌握度

- **典型表现**：家长端只给一个分数雷达图，"为什么说孩子除法薄弱"无法追溯——看不到证据、看不到时间、看不到推理。
- **为什么错**：家长是付费决策者与共学者，黑盒分数无法指导家庭辅导，也难以建立对产品的信任；一旦掌握度出错（必然会发生），无解释出口只能被整体否定。
- **正确原则**：家长端报告可解释——哪些证据、何时产生、推出什么结论，逐条可追溯（规范 7.5 / 8.3）。

## 6. 一句话总结

**记忆域**：先设计遗忘，再设计记忆；先设计隔离，再设计共享；先问"这条记忆对孩子说什么"，再问"这条记忆存哪里"。

**交互·推荐·掌握度域**：主动但不打扰，话痨但不脱锚；不问年龄只问已知，不设门禁只看前置；掌握度用来点亮路径，不用来给孩子打分。
